## 1. 总体定位：评价试卷、分析作答、积累生涯证据

在单题系统之上，项目进一步扩展到试卷和学生整个学习过程。试卷维度包含两个评价对象：一是试卷本身是否符合教学与测评目标，二是学生在这次考试中如何作答、在哪里失分以及时间如何分配。生涯维度持续积累作业、考试和错题等证据，形成知识点与套路的掌握记录、长期能力评价，并支持具有长期记忆和系统工具调用能力的个人 AI 助教，再为每次试卷分析和后续学习安排提供历史参照。

三者的关系是：**用模板明确一份试卷要考什么、考到什么程度；用步骤与作答时间线分析学生这次怎样完成；用长期记录判断这次表现与以往是否一致，并通过后续训练核实原因。**

```text
预设试卷模板 + 提示词
       ├→ 评价已有试卷是否符合目标
       └→ 一键生成试卷 → 单题系统逐题解析、校验 → 整卷检查
                                                    ↓
                           学生作答 + 批改结果 + 可用的时间线
                                                    ↓
                                            本次整卷作答分析
                                                    ↕
课时作业 / 考试 / 错题 / 初始测试 → 生涯掌握与长期能力记录
                                                    ↓
                              个人 AI 助教调用工具，协同教师
                                                    ↓
                              综合研判失分 → 训练与复测 → 新证据
```

## 2. 预设模板：评价与生成共用的目标依据

系统提供若干预设试卷模板，用于描述不同教学阶段和考试目的下的要求。模板是评价已有试卷的参照，也是一键生成新试卷的约束依据。具体模板名称、数量和参数以另行维护的模板定义为准。

| 模板内容 | 作用 |
| --- | --- |
| 使用目的与适用学习范围 | 说明是课时练习、阶段测验或综合考试等场景，以及允许考查的知识范围 |
| 题型、题数、分值与总时长 | 规定卷面结构与考试条件 |
| 知识点与套路的覆盖目标 | 规定应考内容、重点、题数或分值区间，避免遗漏或过度重复 |
| 单题及步骤难度要求 | 规定难度分布、关键步骤要求与梯度，避免只看整题标签 |
| 评分维度、权重与判定规则 | 说明哪些要求必须满足、哪些用于评价接近程度，以及如何形成得分 |

模板负责声明可检查的要求，提示词负责补充命题风格、表达方式和特殊教学意图。用于打分的目标应尽量显式记录，使生成、检查和评价采用同一口径。

## 3. 试卷质量评价：这份卷子是否符合预定目标

### 3.1 从每道题、每一步汇总到整张卷

已有试卷先进入单题系统，逐题得到解答、知识点、套路和步骤难度，再与选定模板对照，形成整卷质量评价。

- **知识点覆盖：** 是否覆盖模板要求的知识点，重点内容的比重是否合理，有无超出适用学习范围的内容。
- **套路覆盖：** 是否考查预期方法，是否存在多道题重复训练相同套路而遗漏其他目标的情况。
- **步骤难度：** 检查每道题各步骤的难度，识别难点集中在哪些操作，以及单题难度标签可能掩盖的局部难点。
- **整卷分布：** 检查难度梯度、分值与内容分布是否符合模板，是否存在局部负担过重或内容过度集中的情况。

覆盖评价应区分主要考查内容与解题时顺带使用的前置知识，也应考虑多解法：参考解法出现某个套路，不一定意味着所有正确解法都必须使用它。

“出得好不好”应落实为“对特定教学目的和学生范围是否合适”。覆盖越广、难度越高并不自动意味着试卷越好，同一份试卷采用不同模板也可能得到不同评价。

### 3.2 模板得分与教师反馈

系统依据模板中的覆盖目标、难度要求和评分规则给出分项评价、综合得分及对应证据，同时指出未能确认的标签或要求。

本项目目前缺少与自身知识点、套路和步骤难度口径对应的试卷质量标注数据，因此初期以教师经验制定和修订模板、评分权重与评价标准，并收集教师对系统评价的反馈。教师经验用于建立可讨论、可校正的初始标准，不能直接替代对评分有效性的验证。

可以先保留多名教师对同一份卷子的分项评价与分歧，逐步校准规则。结构化规则可以先用于打分，不必等待训练数据齐备；但标签不完整、难度尚未确认时，应标注评价范围或暂定状态，不能把未识别内容直接算成未覆盖。

## 4. 一键生成试卷：模板约束下调用单题能力

用户选择预设模板并补充提示词，系统据此组织题目，完成单题校验和整卷检查后输出试卷。设计上可以从已有题库选题，也可以调用单题出题能力生成补充题目，具体采用哪种方式由组卷策略决定。

基本流程为：

1. 读取模板与提示词，确定题目结构、知识点和套路覆盖、难度及适用范围。
2. 将整卷目标分配到各个题位，避免逐题独立生成后才发现整体偏离要求。
3. 选取或生成候选题，复用单题系统的解析、步骤划分、难度评价与校验；已有可靠解析可以复用。
4. 汇总整卷覆盖与难度，再按同一模板检查重复、遗漏和偏离要求的题位，必要时替换或重新生成。
5. 输出学生用卷、参考答案与解析，以及可供复核的模板符合情况。

**单题能够解出，是整卷生成的基础条件；整张卷仍需检查覆盖、结构与难度是否符合模板。** 一键生成的目标是完成这条组织和检查流程，不能把模型按提示词一次写出若干题目视为已经满足整卷要求。

## 5. 学生整卷作答分析：从用时分布追踪失分过程

### 5.1 用时间戳还原考试中的作答顺序

面向无纸化考试场景，计划结合手写笔时间戳、切题、回看与修改事件，分析学生在各题、各小问和可识别步骤上的时间分配，观察是否长时间停留在某题、频繁返回某一步，或因前面耗时过多而使后续题目未能完成。

逐题用时应汇总实际关联到该题的多个作答时段，区分首次作答、返回修改与检查；跨题的停顿或无法归属的时间单独保留。只有首末笔时间，不能准确代表一道题的全部思考时间；没有落笔也不代表没有读题、心算或规划。

在此基础上，结合批改结果定位时间主要消耗在哪些步骤、是否获得相应结果，以及失分发生在何时。没有时间线的历史试卷仍可进行内容与步骤分析，但不补造逐题、逐步用时。

### 5.2 从事实提出解释，再给出可验证建议

综合研判可以考虑知识或套路掌握、答题策略、计算执行、临场状态等不同因素，这些因素可能共同作用，不应强行归入单一原因。

| 可能方向 | 可以核对的依据 | 后续建议或验证方式 |
| --- | --- | --- |
| 知识或套路掌握问题 | 同类步骤在多次独立作答中反复出错，提示后能完成而独立完成困难 | 补充前置知识、步骤训练或同套路新题复测 |
| 时间分配或答题策略问题 | 在某题持续尝试且进展有限，后续存在原本能够完成的题目未作答；需结合历史能力记录核实 | 练习分轮作答、暂时跳过与返回检查，并在下一次考试验证 |
| 执行熟练度问题 | 方法选择正确，但计算耗时、重复修改或局部错误较多 | 针对相应步骤练习计算与书写，并比较后续用时和正确率 |
| 临场状态或学生自述的心态因素 | 本次表现与以往差异较大，并有学生对当时紧张、犹豫等情况的说明 | 结合学生复盘、相似条件下的作答与后续考试继续核实，避免仅凭时间线定性 |

例如，以往能够独立完成的套路，本次耗时增加，不应立刻认定为套路未掌握；但仅凭历史答对，也不能排除掌握不稳定、题目变式更难等解释。“这次确实在某题停留很久”与“为什么停留很久”需要分开记录。

建议应对应具体行为和验证目标，例如“下一次先完成可独立解决的题目，再返回卡住的题”，而不是仅输出“提高效率”或“调整心态”。确切的用时阈值应结合考试条件、题目要求与学生记录确定，不预设适用于所有学生的统一限时。

### 5.3 数据缺口与初期办法

本项目尚缺少与自身步骤体系对应、同时包含真实考试时间线和经核实失分原因的标注数据。初期可以先提供用时分布、作答回放和教师辅助复盘，再积累教师标注与学生自述。

可观察的时间与作答事实、模型提出的可能原因、教师或学生确认的信息应分别保留。首先验证增加时间信息是否改善定位和建议，再研究训练专门的分析模型，不能把 AI 生成的归因直接当作训练真值。

## 6. 生涯维度：两条可以并行的长期建档路线

生涯维度计划持续记录学生在知识点与套路上的掌握变化。这里的“生涯”指学习过程中的长期档案，不仅是累计分数或错题数量。完整方案目前处于设计阶段。

### 6.1 路线一：跟随课时作业，建立知识点掌握记录

围绕每一天、每个课时的作业，结合该课时讲授的知识点、题目及步骤表现，持续更新学生的知识点掌握评价。

这条路线适合从较早学习阶段就开始使用系统的学生，能形成随课程推进的连续记录；同时对学校和教师的配合要求较高，需要稳定获得课时安排、作业内容、作答与批改结果，并维护它们与知识点的对应关系。

作业是否完成只是起点，知识点评价还需结合独立作答情况、正确性、所需帮助与后续复测。没有完成或没有提交某次作业，不能直接记作对应知识点不掌握。

### 6.2 路线二：从考试与错题进入，建立套路掌握记录

通过每次考试、错题输入及后续复测，逐步积累学生在各类套路及其步骤上的表现，更新套路掌握评价。这条路线不要求补齐全部课时作业，适合中途加入系统或难以持续接入学校作业的学生。

对于缺乏历史记录的新学生，也可以安排覆盖面较广、用时较长的先导测试，建立初始能力基线，再通过日常考试、练习和错题反馈持续修正。具体测试长度、覆盖范围与题目选择需另行设计，一次测试不要求穷尽全部套路。

错题输入主要提供失败证据，不能独立代表全部掌握情况。需要尽可能纳入考试中的正确作答与新的独立复测；没有被考查的套路保留未知，不能算作不会。

### 6.3 两条路线如何合并

两条路线可以单独启动，也可以共同使用。它们的区别在于主要证据来源与建档入口，而不是学生只能选择其中一条。

| 路线 | 主要入口 | 主要更新对象 | 适合的接入方式 |
| --- | --- | --- | --- |
| 课时作业路线 | 连续的课时作业及复测 | 知识点掌握评价 | 跟随课程长期使用，学校和教师能够提供支持 |
| 考试与错题路线 | 整卷表现、错题、先导测试及复测 | 套路与相关步骤的掌握评价 | 中途加入，或主要以考试和个人练习提供记录 |

合并时，保留证据来源、作答时间、题目与步骤、是否独立完成、是否得到帮助以及评价是否经确认。两条路线记录了同一次作答时，应合并引用，避免重复计入证据。

知识点和套路相互关联，但不能简单用一个分数替代另一个：掌握相关知识点，不等于已经熟练掌握组合这些知识的套路；一道套路题做错，也不能直接把其包含的全部知识点降为未掌握。缺少证据时应同时保留掌握评价的范围与可信程度，具体评分尺度和更新规则后续校准。

## 7. 生涯数据怎样反哺试卷分析

每次分析试卷时，系统调用考试前已有的掌握记录，与本次作答、步骤错误和时间分配对照。例如：

- 历史上同一步骤反复出现类似问题，本次仍然出错，可优先提出相关能力尚不稳定的解释。
- 历史上能独立完成相近题目，本次因前面某题耗时而未作答，可重点核实答题策略与时间安排。
- 仅有一次错误或本题出现更高难度变式时，应保留未知，通过新题复测补充证据。

综合报告应能回答：**这次失分发生在哪里、有哪些可核对依据、与过去相比有什么变化、哪些原因仍待确认，以及下一步用什么训练或复测来验证。** 不应把所有失分统一归为知识缺陷，也不应把暂时无法解释的差异直接归为心态问题。

分析应保留考试前的历史状态，再用本次结果形成新的记录，避免将本次错误先写入掌握度、随后又把更新后的掌握度当成独立的历史证据来解释这次错误。

最终形成持续更新的过程：课时作业与考试提供证据，生涯记录积累掌握变化，试卷分析结合历史解释当前表现，训练与复测再检验解释和改进是否成立。

## 8. 长期能力评估：形成有证据的综合成长记录

生涯记录还计划支持跨阶段的能力评估，描述学生综合学业水平、学习能力与可观察的学习行为。评价既呈现当前水平，也呈现进步、波动及仍缺少证据的部分。

这里的“综合水平和素质”需要拆成具体维度，不能只用数学题表现给学生作笼统的人格或整体素质评级。数学系统首先评价数学学习相关能力；其他方面需要相应任务、教师观察和学生说明来支持。

| 评价维度 | 可使用的证据 | 评价要回答的问题 |
| --- | --- | --- |
| 知识理解与应用 | 作业、概念辨析、不同情境下的独立作答 | 是否理解知识含义及条件，能否实际应用 |
| 方法识别与迁移 | 套路选择、易混淆方法比较、新变式表现 | 能否识别方法并在变化情境中使用 |
| 推理与表达 | 步骤之间的依据、证明完整性、解释任务 | 能否说明推导理由并组织完整表达 |
| 计算与执行 | 计算错误、独立完成程度、相近任务用时 | 是否准确、熟练地执行已选择的方法 |
| 复盘与自我调节 | 学生订正说明、主动求助、计划调整和复测 | 是否能识别问题、选择帮助并检验改进 |
| 进步与保持 | 可比较任务中的长期变化、延迟复测 | 改进是否持续，是否出现反复或新的困难 |

报告采用“维度表现、时间变化、支持证据、不同表现、待验证事项、下一阶段目标”的结构。数据不足的维度保留未知；同一任务的多次重做不能当作多份独立能力证据。

比较进步时需要考虑题目难度、任务类型、课程阶段、是否得到提示以及评价版本的变化。试卷变容易或 AI 帮助增加导致的分数提高，不应直接解释为能力提高。支持个体纵向比较，也可在条件可比时提供群体参照，避免只用班级排名表示成长。

学生与教师可以核对和修正报告依据。关于努力程度、动机或临场状态的解释，应保留来源与适用时段，避免将一次表现固化为长期标签。

### 8.1 知识理解专项测评

增加独立于套路通过率的知识理解任务：解释概念含义、判断公式或定理的适用条件、区分相近概念、寻找反例、构造满足条件的例子，并在不同情境下应用。任务关联知识点、可观察目标与可接受的不同回答，不要求学生必须背出唯一表述。

例如，学生完成求导套路后，可以进一步说明导数的几何意义、判断某个结论需要什么条件，或对过强的结论给出反例。作答表现与原套路结果分别记录，共同构成长期能力依据。

评价区分表达不完整、条件理解有误和数学内容成立，开放回答保留教师复核入口。知识理解任务为新增设计，不能把现有考后信心或状态问卷等同于已经实施该专项测评。主动诊断可以根据需要选择此类任务，但是否答对仍需实际取证。

## 9. 一对一 AI 助教：长期记忆与系统工具调用

### 9.1 助教的定位

专用 Agent 的学生、教师与学校沟通、任务编排及运行边界，单列于 [教学协同 Agent 设计](教学协同Agent设计.md)；官方 DSH、WorkBuddy 与 MCP 的适配见 [系统 Agent 适配设计](系统Agent适配与MCP插件接入设计.md)。

为每名学生提供持续陪伴的一对一 AI 助教。它能够查询生涯记录，记住已确认的学习目标、训练安排、常见困难与此前有效的帮助方式，并调用单题、套路、错题、组卷和生涯分析能力，把建议落实为学习任务。

例如，学生询问“今天应该复习什么”，助教可以结合明天的课时、到期复查与近期错误，推荐具体任务；任务结束后再根据新的独立作答调整安排。数据不充分时先补充诊断，不编造学生历史。

### 9.2 长期记忆分层

| 记忆层 | 保存内容 | 使用方式 |
| --- | --- | --- |
| 原始学习记录 | 作答、批改、笔迹事件、考试与作业来源 | 保留可追溯依据，按任务查询 |
| 结构化能力状态 | 知识点、步骤、套路的表现及证据范围 | 支持推荐、试卷分析和阶段评价 |
| 经过确认的个人记忆 | 学习目标、计划、学生偏好与有效学习办法 | 在相关对话中使用，允许查看、更正和删除 |
| 待验证事项与近期上下文 | 可能薄弱环节、复测计划、当前任务 | 标明日期和来源，出现新证据后更新或撤销 |

长期记忆不是把所有聊天永久塞入提示词，也不是把学生个人信息写进模型权重。每次任务检索相关内容，并保留证据时间与版本；事实、学生自述、教师判断和模型推测分别记录。缓存用于减少重复读取，不承担事实裁决。

### 9.3 MCP 工具调用的设计边界

计划通过统一工具目录暴露系统能力，供助教查询接口说明、输入要求、权限与运行结果。已有内部函数或 HTTP API 需要明确适配后才能作为 MCP 工具使用，不能因功能存在就默认已经开放 MCP。

| 工具能力 | 助教可完成的任务 |
| --- | --- |
| 查询课时、知识点、步骤和套路关系 | 查找学习前置与可选路径 |
| 查询学生本人学习记录 | 读取证据、掌握状态、复查安排及阶段目标 |
| 解题、教学与步骤批改 | 启动具体题目的学习任务并检查作答 |
| 查找错题与题库、生成变式或组卷 | 将训练需求转为题目或题单 |
| 保存学习计划与复测安排 | 将任务落实到后续日程，并记录完成结果 |

工具必须按当前学生、班级和学校的权限返回数据；助教不能通过工具读取其他学生的个人记忆。教师发布的作业、评分标准和正式记录，与助教提出的草稿建议区分。正式考试时按考试模式限制提示与答案工具，考试后的复盘再恢复相应能力。

### 9.4 与教师协作

助教持续观察任务中的学习困难，教师负责教学目标、关键评价和必要的个别沟通。出现反复训练仍无改善、明显持续退步、学生主动求助等情况时，可以向教师形成有证据的关注建议，并记录教师后续判断与处理。

建议内容应说明发生了什么、持续多久、尝试过哪些帮助以及学生如何描述情况。不能仅凭低分、停笔或聊天措辞判定心理状态，也不由系统自动将学生归入某种人格或心理类别。

### 9.5 统一任务预算与停止条件

学校作业、助教补练、套路训练、复习与诊断共用一份任务清单和可用时间预算，避免各模块分别推荐后形成重复或超量任务。预算结合教师安排、学生可用时间及实际完成用时修正，支持先给出预计范围，再通过历史记录逐步校准。

每个任务说明目标、来源、优先级和替代关系。同一道题或相同目标的任务在多处被推荐时先合并；新增补练应检查替换、延期或减少哪项可调整任务，而不是无限追加。教师必做作业不能由个人助教擅自取消，超出预算时向教师或学生说明冲突并协调。

停止条件包括达到本次独立表现目标、用完约定时间、继续练习已无新增证据，或需要教师确认。达到阶段目标后可以结束当日加练，将后续检查放入复查计划；未知或未完成不因任务关闭自动记为掌握。暂停和延期保留下一次接续位置，防止重复从头练习。

该功能为新增设计。知识理解专项、混合训练和后续研究任务均纳入同一预算；其余待深化方案见 [待深化功能研究](待深化功能研究-提示干预与可靠接入.md)。
