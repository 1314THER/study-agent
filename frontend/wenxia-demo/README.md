# 问侠评审展示站（独立前端）

纯静态、只读的项目说明页。评审主线先展示三个研究问题和本轮修订，再说明总体架构、教学对象、数据来源、全国卷失败记录、学生闭环和系统评测。旧站 63 条愿景保留为折叠档案，不将全部愿景写成首期硬验收。

## 本地预览

从仓库根目录运行 `python3 scripts/preview_wenxia.py --port 8303`，打开 <http://127.0.0.1:8303/wenxia-demo/index.html>。预览服务仅监听本机，根路径也会跳转到新版首页；并行静态资源使用扩大的监听队列。无需安装前端构建依赖。

## 交互与来源

- `experience-data.js` 是共享的公开说明数据：七个业务阶段、三库证据映射、三条 Agent 预置轨迹、LoRA 样本流程和 A—H 任务包。示意对象、版本和状态不是真实后端运行结果。
- `site.js` 读取现有 `/showcase/recordings.json` 与 `/showcase/pipeline.json`。主案例为 2023 年全国Ⅰ卷第 17 题；五帧教学会话与三条件批改分别录制。实际模型、时间、会话和来源随记录显示。
- 愿景目录读取 `/showcase/vision-content.json`，显示学生、教师、学校和社会价值共 63 项，支持按对象与课前 / 课堂 / 作业 / 考试 / 复习接续筛选；每项保留旧状态并映射到新版相应章节。
- 六类诊断情境逐项加载普通模型、同信息基线与正式批改流程的 18 份实际保存输出。每例先说明教学难点、学生原答和可接受判断；构造案例不用于报告总体优势。
- 教学链、五时点学情与班级纠错前后交互明确区分历史实录和协议示例；班级人数、评分修订及状态重算为构造数据，不声称是真人试验。
- 数据规模区分题目素材、解析实例、教学词表、候选关联、人工确认和可发布范围。项目组自审补充必修一材料收集 / 课程结构整理基础、约 60 名学生材料仅供内部分析测试、未来约 60 人试用尚待授权、教师与数据负责人角色及 Qwen3.5-9B 必交付；题池候选人工审核通过量和 LoRA 已审核样本均为 0。网站把这些自审事实与可核验审核日志分开标注。
- Benchmark 增加异解、帮助后正确和教师纠错传播三份完整任务档案；研究对照、LoRA 待定配置、外部依赖与尚待量化的工时 / 算力 / 成本在正文分别说明。日历排期锚定 2026-12 至 2027-07；教师端 Agent 为附加研究，不纳入学生系统验收。
- 模型原始输出逐字保留，可切换数学排版 / 原始文本。不完整提示和纠错时提前给出完整结果均作为失败样例，连接提示泄题率等待测指标；不以预期诊断替换保存结果。2025 年数列题与变式记录通过旧站深链回查。
- 录制载入失败会保留五帧静态原文。关闭 JavaScript 时仍可阅读架构、教学对象、技术机制、默认评测任务和来源索引；63 条完整愿景与 18 份实际条件输出需要 JavaScript 载入，载入失败可由旧站归档链接回查。交互不接收作答、不调用模型 API、不写数据库。
- `已有基础 / 拟议设计 / 待验证` 在章节、机制说明与来源索引中标明。约 9B LoRA 必须完成但增益待测；4B / 27B 为扩展或对照。核心学校流程以不依赖商业模型 API 为目标，但断公网任务尚未实测。项目总预算按申请书为 7000 元，基座型号为 Qwen3.5-9B；revision、许可和训练配置预实验后冻结。pgvector、三库新维护流程和完整 Benchmark 效果均待验证。

## 发布接入与兼容

由 `backend.showcase:app` 将 `/`、`/home.html` 映射到本目录。CSS、两个 JS、螳螂 PNG 和补充 SVG 均逐项列入公开白名单；数学排版使用已有本地 KaTeX。原章节锚点、旧入口别名及 `/showcase/index.html` 保留。

旧站快照位于 `frontend/archive/demo-legacy-20261113/`；此次改版不改写快照和原始录制。发布通过现有独立打包器和 Workbench 激活流程，构建发布包不等于已经上线。

## 验收

Python：`.venv/bin/python -m unittest tests.test_showcase tests.test_research_release tests.test_showcase_recordings -q`。

浏览器：`node tests/e2e/wenxia_demo_acceptance.cjs`。使用已安装的 Playwright，可用 `NODE_PATH` 指向模块目录，`PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指向现有 Chrome。可通过 `WENXIA_BASE_URL` 指定预览地址，截图默认保存在 `.runtime/wenxia-acceptance/`。覆盖原文一致性、所有机制切换、失败回退、无 JavaScript、键盘、减少动效和 1440 / 1024 / 390 / 320 宽度。
