准备你的 DeepSeek API Key

一个密钥用于学习教练台的文字解题、图片识别与教学。网页聊天账号和开放平台 API 的计费方式不同，请在开放平台查看余额与实际用量。

  1. 打开官方开放平台。
    前往 DeepSeek 开放平台 ↗，按官方页面提示注册或登录账号。
  2. 查看 API 使用条件与余额。
    在平台控制台确认当前可用模型、计费与余额；如需要充值，按官方平台的说明操作。
  3. 创建 API Key。
    打开 API Keys 页面 ↗，创建新密钥。复制并妥善保存，页面可能只在创建时完整显示。
  4. 填入学习教练台。
    创建账号时把密钥粘贴到「DeepSeek API Key」。以后可在「账号与 API Key」里替换；保存后页面只显示配置状态。

请为学习教练台单独创建一枚密钥。密钥泄露或停止使用时，可在 DeepSeek 平台撤销，并在本系统保存新密钥。不要把密钥放进题目、聊天内容或截图。
