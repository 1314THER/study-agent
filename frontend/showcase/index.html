教学愿景让每个学生，都能获得适合自己的学习支持。

系统通过LLM大模型提供的低成本大批量输出，探索把及时诊断、针对性教学和持续跟进融入日常教育，让学生、教师、学校到社会不必为了补上学习的差距花费过多精力。

以下对照描述系统融入日常教学后希望带来的变化。各项支撑功能的现状见对应章节。

功能进度已有基础已有代码或演示；设计方案待接入教学流程；研究方向待方法与效果验证。

课前准备

原来的困难

大家预习同样的内容，是否具备本节课需要的基础，主要靠自己判断。

教学怎样改变

按本节课的前置要求检查个人准备：已经具备的基础直接带入新课，缺少的概念或操作先安排短任务补上，让学生知道该从哪里开始。

接续功能
  • 课程前置关系已有基础
  • 课前诊断与准备任务设计方案

课堂跟进

原来的困难

课堂讲到哪里就跟到哪里，局部没有听懂的内容容易积累到下一课。

教学怎样改变

共性目标由教师组织课堂教学，个人缺口接到助教讲解、专项任务或教师辅导；补充之后再检查，个人支持与班级进度相互衔接。

接续功能
  • 课堂与个人任务协同设计方案
  • 跨课时学习记录设计方案

个性化作业

原来的困难

全班一份作业，已经会的反复做，基础不足的也只能直接做同一组题。

教学怎样改变

共同必做内容配合个人任务：有人先补基础，有人练局部步骤，有人做变式迁移。题目、帮助方式和题量随表现调整，教师可以查看和修改分配理由。

接续功能
  • 共同与个人作业分配设计方案
  • 套路顺序与知识双路推荐设计方案

统一负担预算

原来的困难

学校作业、错题、助教补练和复习分别加任务，发现的问题越多，额外作业越多。

教学怎样改变

所有任务共同占用一个时间预算。新增补练时合并、替换或延期已有任务；达到当日目标后结束，把必要复查安排到后续日期，避免每个模块各加一份。

接续功能
  • 统一任务与时间预算设计方案
  • 学习任务协同设计方案

搜题诊断

原来的困难

把题目交给工具获得一份答案，拿到解析后仍要自己猜到底哪里不会。

教学怎样改变

把本人作答一并交给助教，先定位具体错误并引用原文；原因有多种解释时，用短任务核实，再把结果接到相应讲解、练习与独立验证。

接续功能
  • 三阶段结构化解题已有基础
  • 作答证据与主动诊断基础已有基础
  • 区分原因的自适应补测设计方案

卡点讲解

原来的困难

一道题从头听到尾，自己已经会的部分也要再听一遍。

教学怎样改变

从实际卡点进入讲解：列式正确而计算出错，就处理计算；概念条件不清，就先补概念再回原题。结合标准过程、详细过程、讲解风格与几何演示帮助理解。

接续功能
  • 分步教学与多种讲解风格已有基础
  • 几何分步演示已有基础
  • 前置补充后返回原题设计方案

分级提示

原来的困难

卡住后直接看完整答案，看懂了这份解析，下一题依然难以独立开始。

教学怎样改变

按需要获得目标提醒、相关知识或关键转化提示，保留自己完成推理的空间；随后逐步减少帮助，通过无提示新题检查独立完成能力。

接续功能
  • 步骤提示与回答检查已有基础
  • 提示分级与逐步撤除研究方向
  • 新题练习与复查已有基础

步骤批改

原来的困难

主要看到对错和扣分，反馈常停在“粗心”“基础不牢”等概括上。

教学怎样改变

逐步查看判断依据：哪一步成立、哪一步缺失、哪段推导需要修正，并回到对应作答核对。正确的替代解法保留自己的路径，评分争议交由教师复核。

接续功能
  • 步骤批改与原文证据已有基础
  • 多解法兼容与复核标记已有基础
  • 教师批改复核设计方案

错因分析

原来的困难

一道大题做错，就觉得整章都不会；已经会的部分也被同一个错误盖住。

教学怎样改变

分别核实概念、方法识别、步骤组合、计算与表达问题，保留已经会的部分；需要时回看书写、返回和修改过程，再用补测区分原因。

接续功能
  • 步骤错因记录已有基础
  • 数字笔迹时间线与回放设计方案
  • 首错与连带错误分析研究方向

合理刷题

原来的困难

按教辅页码、题目数量或个人感觉往下做，很难判断这次练习解决了什么。

教学怎样改变

围绕明确目标选题：知道在练哪个方法或步骤、为什么做这一题、什么表现说明可以继续。六步循环组织套路内训练，套路顺序与知识准备共同决定下一项。

接续功能
  • 套路训练与复查框架已有基础
  • 完整六步循环与双路推荐设计方案

局部步骤训练

原来的困难

只为练一个薄弱步骤，也要反复重做整道大题。

教学怎样改变

把局部困难单独拿出来练，再放回完整题目。例如空间坐标系已会建立，只在求法向量时出错，就集中练该操作，再用新题检查能否正确衔接。

接续功能
  • 独立步骤专项训练设计方案
  • 参考步骤约束的变式生成已有基础

新题迁移

原来的困难

专项练习提示了题目类别就会做，放进综合卷却认不出该用什么方法。

教学怎样改变

从有类别提示的专项练习，走向隐藏类别的混合任务；自行识别方法、解释适用条件，再完成解答。改变条件的新题经重新求解后进入训练，进一步检查迁移。

接续功能
  • 隐藏方法标签的混合训练设计方案
  • 变式生成与三阶段校验已有基础

知识理解

原来的困难

会套公式、会做熟悉题，就容易被视作已经理解相关知识。

教学怎样改变

分别检查会做题和理解概念：除了计算，还要解释含义、辨析条件、寻找反例、比较方法。会求导与理解导数的意义各自留下证据，指导不同的补充任务。

接续功能
  • 知识理解专项测评设计方案
  • 解释、探究与多解比较研究方向

错题管理

原来的困难

拍照、抄题、抄解析，错题收集越来越多，却不容易找到需要再练的内容。

教学怎样改变

把错题变成可检索、可复测的问题记录：查同一步出错的题、看过答案仍待独立完成的题，将结果整理成个人题单，继续组卷、打印或安排复习。

接续功能
  • 题库筛选与错因检索已有基础
  • 题单、组卷与打印已有基础
  • 帮助条件与待复测筛选设计方案

订正复习

原来的困难

订正完成就翻篇，临近考试再集中重刷，很难分清记住原题和真正会用。

教学怎样改变

原题订正之后安排新变式验证，间隔一段时间再独立复查；专项题、混合题和延迟表现分别记录，让下一次复习依据实际保持情况调整。

接续功能
  • 复查日历与间隔排程已有基础
  • 混合与延迟证据衔接设计方案
  • 长期学习证据设计方案

学习计划

原来的困难

计划写成“多做几题”“补一补薄弱章节”，任务和结束条件比较笼统。

教学怎样改变

结合学校作业、近期错误、到期复查与可用时间，给出能执行的安排：今天做什么、为什么做、到哪里结束；遇到新困难时调整任务和预算。

接续功能
  • 套路规划与复查安排已有基础
  • 统一计划与任务预算设计方案
  • 个人助教协调任务设计方案

考试复盘

原来的困难

考后主要看总分、错题和排名，再归结为“时间不够”或“发挥不好”。

教学怎样改变

结合题目、步骤、历史表现与可用时间线分析失分，区分知识不足、执行不熟或时间安排等可能情况；将疑问转成限时与不限时新题等后续核实任务。

接续功能
  • 整卷分析与考后自述已有基础
  • 验证目标与复测关联已有基础
  • 可靠笔迹时间分析设计方案

成长评价

原来的困难

用一次考试分数和班级排名，判断自己最近有没有进步。

教学怎样改变

看到跨阶段的具体变化：过去需要提示的步骤现在能独立完成，过去只会原题现在能做变式，间隔后仍能保持。理解、方法、表达与执行各自积累成长证据。

接续功能
  • 多维长期档案与能力评价设计方案
  • 新题练习与复测关联已有基础

长期助教

原来的困难

每次问问题都像重新认识一次，助教缺少自己的目标、历史和正在进行的任务。

教学怎样改变

个人助教按需查询长期记录，知道已确认目标、进行中的任务和尝试过的办法，接续下一次帮助；学生可以查看并纠正不准确的记录，学习背景随新证据更新。

接续功能
  • 全局教练与内部业务工具已有基础
  • 个人助教与长期记忆设计方案
  • 可修订的学习档案设计方案

帮助可获得性

原来的困难

卡住后等待课堂讲评或教师有空，也可能要另外寻找课外辅导。

教学怎样改变

日常问题及时获得基础讲解和练习支持；需要教师帮助时，带着卡点、已有尝试和未解决问题进入交流。文本、照片和 PDF 提供接入起点，学校按设备条件安排使用。

接续功能
  • 分步教学与多模态输入已有基础
  • 教师关注与辅导衔接设计方案
  • 低门槛接入与可靠恢复研究方向

自主学习

原来的困难

主要依赖别人指出哪里错、决定下一步做什么，自己难以判断学习是否有效。

教学怎样改变

逐渐学会解释困难、选择帮助和验证改进：查看推荐理由，修正错因记录，调整个人任务，用新题判断是否学会；随着独立能力增长，减少所需提示。

接续功能
  • 个人复盘与自主选练已有基础
  • 可解释任务推荐设计方案
  • 提示渐退与自我调节研究方向

精准教学

教师

教师从投入大量时间处理同类事务，变成依据具体学情设计更生动的教学，把精力放到关键个性化判断、人与人的互动和学生心理健康建设上。

学情备课依据

原来的困难

主要凭教材、教参和经验，预判学生这节课可能在哪些地方遇到困难。

教学怎样改变

课程目标与本班真实学情共同决定重点：课前看到哪些前置知识不稳、哪些问题具有共性，再选检查任务、例题与讲法，把教师经验用在具体对象上。

接续功能
  • 课时与前置结构已有基础
  • 学情驱动备课设计方案

备课材料

原来的困难

找资料、选题、整理解析和制作练习分别进行，重复搜集与搬运较多。

教学怎样改变

围绕课时准备可编辑材料，连同知识关系、例题步骤、易混淆条件和练习草稿一起组织；教师选择、核对和调整，使材料服务于本次教学目标。

接续功能
  • 题库与结构化解析已有基础
  • 教案与备课材料组织设计方案

PPT

原来的困难

手动搬运题目、公式、图形和班级统计，为不同课型反复整理。

教学怎样改变

按新课、讲评、复习、公开课或教研的目的组织内容，调用对应题目与学情材料；接入文档工具后生成可修改的 PPT，教师检查实际文件并按课堂需要编辑。

接续功能
  • PPT 与课型工作流设计方案
  • MCP 与宿主文档工具接入设计方案

课堂演示

原来的困难

主要通过静态板书、口头描述和整段解析，展示较复杂的推理过程。

教学怎样改变

围绕推理逐步展开辅助构造、函数变化、条件改变和解法比较；教师可以暂停在关键一步追问依据，再让学生尝试，让演示服务于理解检查。

接续功能
  • 几何分步演示与多种解析已有基础
  • 课堂演示素材编排设计方案
  • 解释与多解法教学研究方向

理解检查

原来的困难

依据举手、抽问和少数学生反应，推断全班是否理解。

教学怎样改变

课堂观察配合短诊断与后续独立作答，查看不同学生卡在哪里；对“似乎听懂”的内容安排小任务核实，再决定继续推进或补充讲解。

接续功能
  • 诊断建议与验证目标已有基础
  • 课堂短诊断与结果汇总设计方案

课堂时间分配

原来的困难

全班一起讲、一起练，教师难以同时兼顾不同准备程度的学生。

教学怎样改变

共性关键问题全班处理，相似困难安排小组补充，局部问题交给个人任务或辅导；教师依据问题范围分配时间，并从后续作答判断安排是否合适。

接续功能
  • 全班、小组与个别支持安排设计方案
  • 教学任务协同设计方案

作业分配

原来的困难

凭经验选一份全班作业，针对个人差异的安排需要大量额外劳动。

教学怎样改变

系统准备共同任务与个人差异草案，呈现每题的目标、分配理由和预计负担；教师审核、调整后布置，再随学生表现更新，并与其他任务共享预算。

接续功能
  • 个性化作业草案与审核设计方案
  • 统一任务预算设计方案

批改复核

原来的困难

大量时间用于重复判断相似答案、标记相似错误，关键争议淹没在常规工作中。

教学怎样改变

系统处理常规步骤判断，教师集中核对评分争议、替代解法和证据不足的情况；从结论跳回原始作答，修正判断，并让更正进入后续教学记录。

接续功能
  • 步骤批改与复核标记已有基础
  • 教师批改审核与更正设计方案
  • 更正影响回溯研究方向

班级学情

原来的困难

主要查看平均分、正确率和错得最多的题，难以区分同分背后的不同困难。

教学怎样改变

查看知识、步骤和方法上的问题分布：同一道题答错的学生可能需要不同帮助，不同题目出错也可能指向同一步骤；教师可展开具体作答核对。

接续功能
  • 知识、步骤与套路共同表示已有基础
  • 班级证据汇总与筛选设计方案

问题讲评

原来的困难

试卷按题号从头讲到尾，所有学生再次听相同的整段解析。

教学怎样改变

按问题组织讲评：共同讨论关键方法，小组处理相似困难，个人补特定步骤；用题库筛选准备对应材料，并在讲评后检查各类问题是否改善。

接续功能
  • 错题与步骤筛选已有基础
  • 针对性讲评与分组任务设计方案

出卷评卷

原来的困难
