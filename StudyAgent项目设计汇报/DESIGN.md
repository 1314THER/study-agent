# DESIGN.md · StudyAgent 项目设计汇报（技术评审版）

## 0. 定位与调性

面向**技术评审 / 内部汇报**的 124 页完整版汇报。核心诉求是**可读性 + 可追溯**：评审者要能快速判断"这个功能做到哪一步、依据哪份文档哪一节"。因此全篇采用**简洁科技风**：浅色底、深蓝主色、青蓝强调、1px 细线分隔、克制的几何网格，不使用照片级配图与阴影堆砌。

风格路由判定：**不属于**学术答辩 / 商务咨询 / 政务红金三类垂直领域（属于技术产品内部评审）→ 走**通用设计原则 + 用户显式指令覆盖**（用户已指定"简洁科技风"及"生成示意图占位"）。

## 1. 画布与母版（A/B/C 三区）

- 画布：**1280 × 720 px**（16:9）
- 页面 padding：**上下 20px、左右 70px** → 内容可用宽度 **1140px**

| 母版区 | 垂直区间 | 高度 | 内容规则 |
| :--- | :--- | :--- | :--- |
| **A · 标题块** | 0–120px | 120px | 左上：章节标签 `03 / 单题引擎`（14px，`#7A8699`）；下方：页面主标题（32px bold，`#0E2340`）；右上：实现状态标签胶囊 |
| **B · 内容区** | 120–660px | 540px | 正文 / 卡片 / 表格 / 结构图 / 界面示意图 |
| **C · 页脚条** | 660–720px | 60px | 左：来源标注 `依据：xxx.md §x`（13px `#7A8699`）；右：页码 `NN / 124`（14px `#7A8699`）；中间 1px 分隔线 `#E3E8EF` |

- 封面 / 章节过渡 / 结束页使用自定义版式，可省略 C 区页码或改为居中。
- 同类内容页的标题位置、页码位置**全篇固定**，不逐页变动。

## 2. 色彩系统

### 2.1 色彩池（4 色 + 中性）

| 角色 | Hex | 用途 |
| :--- | :--- | :--- |
| **主色** | `#0E2340` | 标题、深色块、章节大字、强调文字 |
| **辅色** | `#1E7BE0` | 结构图主线条、卡片顶部条、焦点数字、进度元素 |
| **强调色** | `#00A9B5` | 仅用于巨型锚点数字、关键结论高亮、状态"已实现"标识 |
| **底衬色** | `#F5F7FA` | 卡片背景、表格斑马纹、示意图底 |
| 中性文本 | `#333A45` | 正文 |
| 次级文本 | `#7A8699` | 页脚、章节标签、说明 |
| 分隔线 | `#E3E8EF` | 1px 线框 |

### 2.2 状态色（仅用于右上角状态胶囊与状态总表，不参与页面主配色）

| 状态 | Hex | 含义 |
| :--- | :--- | :--- |
| 已实现 | `#1E9E62` | 代码已落地并经静态核对 |
| 部分实现 | `#E8A33D` | 有代码基础但存在明确缺口 |
| 设计中 | `#1E7BE0` | 仅有设计文档，未实现 |
| 待研究 | `#98A2B3` | 研究性方向，无实现承诺 |

### 2.3 面积分配

| 页面角色 | 主色 | 辅色 | 强调色 | 底衬 |
| :--- | :--- | :--- | :--- | :--- |
| Hero 页（封面 / 章节页 / 巨型数据页 / 状态总表） | ≤ 55% | ≤ 25% | 15–20% | 剩余 |
| Supporting 页（常规内容页） | ≤ 25% | ≤ 20% | ≤ 5% | 剩余 |

### 2.4 渐变与透明

- 卡片顶部条：`linear-gradient(90deg, #1E7BE0 0%, #00A9B5 100%)`，高 4px
- 章节页右侧装饰块：`linear-gradient(135deg, #0E2340 0%, rgba(30,123,224,0.15) 100%)`，`opacity: 0.08`
- 背景网格：SVG 1px `#E3E8EF`，`opacity: 0.5`，仅封面 / 章节页使用
- 卡片阴影：`0 2px 10px rgba(14,35,64,0.06)`（轻投影，禁止厚重阴影）

## 4. 信息密度门禁

| 页面类型 | 正文字数下限 | 主视觉占 B 区 | 留白上限 |
| :--- | :--- | :--- | :--- |
| 封面 | 20 | ≥ 35% | 40% |
| 目录 | 120（合计） | — | 25% |
| 内容页 · 单主题 | **180** | ≥ 30% | 35% |
| 内容页 · 卡片组 | 每卡 ≥ 60，合计 ≥ 240 | — | 30% |
| 结构图页 | 80（洞察文字） | ≥ 50% | 30% |
| 界面示意图页 | 100 | ≥ 45% | 30% |
| 章节过渡 | 30 | ≥ 40% | 45% |
| 结束页 | 25 | — | — |

- 卡片填充率 ≥ 85%；高 ≥ 380px 的卡片正文 ≥ 90 字。
- 每张内容页必须有 ≥ 1 个视觉锚点（≥ 44px 元素，或占 B 区 ≥ 40% 的图/色块）。
- 连续 ≥ 2 页版式完全一致 → 必须改版式（穿插卡片页 / 表格页 / 结构图页）。

## 5. 配图系统

- 本 deck **不使用照片级 ImageGen 配图**（技术评审场景，具象照片会稀释信息密度）。
- 全部视觉元素分两类：
  - **SVG 结构图**：流程图、架构图、分层塔、闭环图、矩阵、漏斗、时间轴、雷达示意、状态机 —— 页面主视觉，占 B 区 ≥ 45%
  - **SVG 界面示意图（占位）**：用线框 + 虚线 + 中文标注模拟产品界面，右下角固定标注 `示意占位 · 待替换为实际截图 Sxx`，编号 `S01–S35` 与《待补截图清单.md》一一对应
- 文件命名：`assets/` 下只允许英文短名；本 deck 不引用外部图片，全部内联 SVG。

## 8. 通用禁忌

- 同一页出现 ≥ 2 套主色板
- 状态胶囊位置逐页漂移（必须固定 A 区右上）
- 表格字号 < 15px 或行高 < 1.3
- 界面示意图缺少 `示意占位` 标注与编号
- 章节页与内容页混用同一版式
