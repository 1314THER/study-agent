# STORY.md · StudyAgent 项目设计汇报（技术评审版）

## 1. 叙事目标

一个核心判断：**StudyAgent 不是"接了个大模型的题库"，而是一套以「结构化步骤」为共同表示的学习系统。**

评审者需要在 30 分钟内回答三个问题：

1. **这套系统的核心抽象是什么？**（步骤 —— 解题、批改、教学、出题共用同一套表示）
2. **现在到底做到哪一步、能力边界在哪？**（已实现 / 部分实现 / 设计中 / 待研究，逐页标注）
3. **它凭什么说自己有效、准备怎么验证？**（研究对照、冷启动路线、效果评价边界）

叙事主线：**抽象 → 现状 → 引擎 → 三端与场景 → 协同与接入 → 边界与演进**。

## 4. 三条贯穿全篇的金句（用于 hero 页锚点）

1. **"AI 解题是单题功能的基石，结构化步骤是其他单题功能共用的基础。"**
2. **"把解题过程显式拆成可以引用、判断和训练的步骤，使模型的判断有明确对象。"**
3. **"工具使用次数、AI 帮助下的完成率或单次平均分上涨，不能独立证明该目标实现。"**
