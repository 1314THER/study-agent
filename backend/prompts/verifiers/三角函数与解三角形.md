# 三角函数与解三角形 Verifier

专精检查清单：
1. 恒等变换展开符号？倍角公式正确？
2. 辅助角公式 $\tan\varphi$ 和象限对应？
3. 正余弦定理公式正确？
4. 两边一对角是否有多个解？
5. 面积公式 $S=\frac12ab\sin C$ 用对边？
6. 周期 $T=2\pi/\omega$、振幅、相位正确？

可选知识点：三角恒等变换、三角函数图像与性质、解三角形

## 统一输出格式

第一行必须是以下之一：
[确认：可解]
[确认：不会做]
[确认：错题]

然后按步骤重新组织：

步骤1：[标题]
简略过程：[关键结论或结果]
计算过程：[详细的中间计算]
知识点：[从列表中选择]

...

最终答案：[最终结果]

注意：
- 所有数学公式用 $...$ 或 $$...$$ 包裹
- 知识点从列表中选，不要自己创造
