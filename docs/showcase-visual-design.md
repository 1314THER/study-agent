# 科研展示站：开屏视觉设计

2026-10-25。本轮只重做欢迎页，章节正文、数学案例和研究记录保持原有内容。

## 实际浏览的页面

| 页面 | 借鉴的设计关系 | 在本项目中的使用 |
| --- | --- | --- |
| [Apple iPad Pro](https://www.apple.com/ipad-pro/) | 用足够大的真实主体形成视觉中心，控制文字和动作的数量 | 放大原有数学／love 笔迹，由笔迹承担开屏主视觉 |
| [Resend](https://resend.com/) | 标题、主要内容和入口有清楚的信息轴与主次关系 | 项目名称移到左上，进入动作落在右下，不再将三个元素居中堆叠 |
| [Mathigon](https://mathigon.org/) | 数学内容自身可以成为可辨认的视觉素材 | 沿用项目原始数学笔迹，不加入与数学教学无关的图片 |
| [Raycast](https://www.raycast.com/) | 少量文字与清楚入口组成简洁首屏 | 保持一行项目名称和一个入口，避免为填充留白而增加文案 |

上述页面通过公开网站浏览与桌面截图核对。仅参考构图与层级，没有复制其图片、字体、组件或源码。Linear 页面也曾浏览，但截图未完整加载其主视觉，未据此决定构图。

## 最终构图

纯白底、墨黑笔迹与原始红色尾笔。左上保留 `study-agent项目介绍页面`，细线建立标题的信息轴；笔迹从左侧舒展到中部，右下是文字加圆形箭头的“点击进入预览”。只有一个可操作入口。

欢迎页使用独立的 `frontend/showcase/launch-lettering.svg`，缩紧该副本的 viewBox，使布局按可见墨迹对齐；共享的原始 `frontend/launch-lettering.svg` 不变。love 沿原路径揭示，持续 1.8 秒，采用先快后慢、末端速度趋近于零的缓动。页面不会自动进入。

手机端保持同一信息顺序，标题完整一行、笔迹完整显示、入口沿底部排布。短屏允许欢迎层内部正常滚动。初始焦点在标题，Tab 可进入按钮并用 Enter 打开正文；键盘焦点仍清楚可见。减少动态效果模式直接显示完成态，仍保留明确入口。
