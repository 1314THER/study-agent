# 科研展示站：开屏视觉设计

2026-10-25。欢迎页按用户追加要求采用科幻风背景，保留数学／love 原始笔形；同步增加刷新恢复与正式站备案入口。

## 实际浏览的页面

| 页面 | 借鉴的设计关系 | 在本项目中的使用 |
| --- | --- | --- |
| [Apple iPad Pro](https://www.apple.com/ipad-pro/) | 用足够大的真实主体形成视觉中心，控制文字和动作的数量 | 放大原有数学／love 笔迹，由笔迹承担开屏主视觉 |
| [Resend](https://resend.com/) | 标题、主要内容和入口有清楚的信息轴与主次关系 | 项目名称移到左上，进入动作落在右下，不再将三个元素居中堆叠 |
| [Mathigon](https://mathigon.org/) | 数学内容自身可以成为可辨认的视觉素材 | 沿用项目原始数学笔迹，不加入与数学教学无关的图片 |
| [Raycast](https://www.raycast.com/) | 少量文字与清楚入口组成简洁首屏 | 保持一行项目名称和一个入口，避免为填充留白而增加文案 |

上述页面通过公开网站浏览与桌面截图核对。仅参考构图与层级，没有复制其图片、字体、组件或源码。Linear 页面也曾浏览，但截图未完整加载其主视觉，未据此决定构图。

## 最终构图

全站统一黑色 `#080808`、深灰 `#111111`／`#191919` 与灰边 `#333333`；主文字 `#F5F5F5`、辅助文字 `#B8B8B8`，数学与love保留原始笔形，分别使用白色与红色 `#FF555E`。左上保留 `study-agent项目介绍页面`，笔迹从左侧舒展到中部，右下使用切角轮廓“点击进入预览”按钮。背景为原生 SVG 透视坐标网格、渐隐椭圆轨道与一段缓慢运动的光轨，降低亮度以保持笔迹与入口的主次。

欢迎页使用独立的 `frontend/showcase/launch-lettering.svg`，缩紧该副本的 viewBox，使布局按可见墨迹对齐；共享的原始 `frontend/launch-lettering.svg` 不变。love 沿原路径揭示，持续 1.8 秒，采用先快后慢、末端速度趋近于零的缓动。首次浏览等待点击进入；已经进入的同一标签页刷新后直接恢复正文。

手机端保持同一信息顺序，标题完整一行、笔迹完整显示、入口沿底部排布。短屏允许欢迎层内部正常滚动。初始焦点在标题，Tab 可进入按钮并用 Enter 打开正文；键盘焦点仍清楚可见。减少动态效果模式直接显示完成态，仍保留明确入口。

## 刷新与底部入口

同标签页的 sessionStorage 只保存公开演示的界面选择与阅读位置，包括全国卷案例、解析老师、单题模式、诊断情境与条件、图解页签、教学和几何进度、题库筛选和公开选题 ID。刷新或历史返回时，在数据、题库详情和字体加载后恢复章节内偏移；明确的新章节链接优先。存储不可用时继续正常展示。

开屏与正文底部均列出 [正式站首页](https://150.chat/)、[学习系统](https://150.chat/home.html) 和 [渝ICP备2026024246号-1](https://beian.miit.gov.cn/)。备案号与地址复用现有正式入口 `deploy/public/index.html` 的内容。

## 章节交接

根据用户对 Apple 网页动画的追加要求，重新浏览 [iPad Pro 官方页面](https://www.apple.com/ipad-pro/) 并核对滚动前后的画面。展示站采用原生滚动驱动的章节交接：上一章产出聚焦、SVG连线推进、下一章输入与完整标题出现。15处交接各自对应原文中的具体逻辑，使用短暂的sticky舞台；目录与程序化跳转另有约900毫秒的过渡层。浏览器滚轮、锚点和历史保持原有行为。

`transitions.js`只测量当前可见交接区，批量更新transform、opacity与SVG线条；仅活跃元素使用will-change。减少动态效果模式直接展示完成态，不增加停留高度或导航遮罩。

## 内嵌数据集

数据集作为第3章放在基础表示与单题能力之间，先展示五项核心规模、素材到教学应用的三步流程和四项明确假设的规划测算；完整统计另开详情页。章节设计前再次完整阅读《项目名词与教学关系定义》与《当前实现能力与名词数量》，原文哈希和聚合快照哈希纳入主展示源映射。主导航及章节目录均直接定位 `#dataset`，刷新恢复和章节交接与其他章节共用。

## 章节导航与作答排版

顶部改为单行索引，15项导航逐一对应15个章节，章节标题前显示相同的短名称。当前章节同步高亮，窄窗口下当前项自动进入横向可见范围；手机使用完整目录。原来的第二行分组主线移除。

学生作答的中文使用手写字体，标点单独调整；可靠识别的数学片段由本地KaTeX排版，支持分数、根号、上下标和常见符号。保留原始data-source；不化简、修正学生错误，也不推断歧义算式。
