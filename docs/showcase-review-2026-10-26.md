# Demo 愿景改版与整站复核

日期：2026-10-26。交付范围：本地展示站与生成源，不部署服务器。

## 阅读结构与本轮设计

独立数学 love 欢迎页之后进入教学愿景，再进入项目亮点与原有功能、研究章节。顶部和手机目录共 12 个主题，原有 15 个研究内容单元保留。

愿景保留学生 21、教师 17、学校 17、社会价值 8 项，共 63 项。按最新要求取消页面表格和红色强调，用一条连续主线串联各环节；每个环节展示“原来的困难 → 教学怎样改变 → 接续功能”。四个分支默认各显示 2 项，其余可展开；63 项正文仍完整保留，支撑功能链接进入原有章节。

颜色承担明确用途：灰色说明原有困难、背景和功能状态；白色与字重突出教学变化；蓝色标识连接、当前阅读位置和可点击功能。手机将环节内的横向连接改为纵向，保留主线、章内定位与跳过入口。

文案源见 [教学愿景与社会价值](教学愿景与社会价值.md)，独立内容节点见 [vision-content.json](../frontend/showcase/vision-content.json)。愿景参考的 12 份 Markdown 全文读取，共 1,838 行；151 个功能标签逐一核对，其中“支持行动与复测跟踪”调整为研究方向。

## 文案与事实修改

- 逐段审读原有 15 个研究单元、七块亮点、动态场景和生成器文案。把“证据、口径、能力、闭环”等抽象表达改为具体作答、任务、条件与后续动作。
- 解释三阶段解题、OCR、六个训练阶段等首次出现的术语，分清数学步骤与训练阶段。
- 目录和素材总量分别说明，避免将 23,261 道入池素材表述为全部完成关联与审核。
- 将连续否定句改成现状和核实方法；保留原始作答缺失、替代正确解法、提示条件与研究范围等必要信息。
- 笔迹停顿对应的是停顿所在步骤；原因结合推导、追问与补测核实。能力图中的心态信息结合学生说明与教师交流，避免仅凭用时作判断。
- 教师、学校、长期档案、外部 MCP 等段落标明相应方案状态。真实模型回答、录制内容与数据快照逐字保留。
- 保留用户确认的首屏宣言、七个亮点主题、作者信息和数学 love 视觉。

## 文献与公共来源

逐项核对 18 条研究的身份、指定版本、方法、关键数字与结果定位，未发现链接到无关论文。已修正：

- Verify-then-Generate：说明 MathDial 中使用模拟学生推理链，由教师标注首错，与真实手写作答区分。
- SwS：提高幅度改为相对同规模 BaseRL 的 10.0、7.7 **个百分点**。
- Darwin Gödel Machine：明确有效候选及其得分进入档案，较低得分的版本也可成为后续起点。
- ReMe：网页固定到 v1，与引用 PDF 一致。
- Numbas：直达自适应批改设计文档；CogChain、PFA：改为论文专页并补正确页码。
- EduLoop-Agent：注明离线模拟与三名学生案例，不写成课堂学习收益。

愿景的三项政策保留用户指定原链接，并补可读政府转载。原链接访问超时或返回 403 时，单独记录访问状态。社会价值是长期目标，政策方向用于解释设计用途。

GLM-5.3-Flash 成本按智谱官方价目试算：10,000 输入加 2,000 输出 Token 为 ¥0.0136；每日 10 次、30 天约 ¥4.08 / 人。页面明确这是示例用量的模型 API 费用，完整服务预算另计设备、服务器、审核及实际调用量。

## 验收结果

- 展示构建一致性检查、数据集构建一致性检查、Git 空白检查通过。
- 57 项相关单元测试通过，含 63 项全文、功能标签、来源哈希、价格算术与发布资产的检查。
- Chrome 浏览器在 1440、980、390、320 像素下完成回归；愿景无表格，默认每组 2 项、可展开/收起，页面无横向溢出。
- 两处跳过入口的键盘焦点到达项目亮点；四分支定位、子锚点、顶部目录、刷新恢复正常。
- 欢迎书写、红色 CTA、七块亮点图、12 个章节交接、自然滚动的整块 3D 拉出面板、减少动态效果模式正常。
- 原有两道全国卷、八份四老师解析、六类诊断输入和十八份回答保持；几何、侧栏批注、题库筛选、组卷、打印与复查回归通过。
- 无 JavaScript 时愿景及原有研究正文可读；浏览器网络只有同源 GET，无模型调用、业务写入或 Cookie。
- `data.json`、`pipeline.json`、`recordings.json`、`dataset-data.json` 与本轮之前的 Git 内容完全一致。

浏览器自动验收使用本机 Chrome；本轮未运行 Safari / WebKit。现有 Safari 标志修复采用本地透明 PNG，并继续保留。

## 展示效果判断

愿景负责说明教学日常的变化，亮点负责解释设计支点，后续章节承接机制、研究与实现细节。读者可以按四个角色深入阅读，也可以随时跳到项目亮点。

63 项完整内容仍是一段长阅读。章内导航、两处跳过入口和每项的功能链接承担分流；本轮保留全部正文，默认每组 2 项、其余展开，刷新保留展开状态；无 JavaScript 时全文直接显示。
