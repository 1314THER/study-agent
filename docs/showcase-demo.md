# 项目展示站

公开入口保持 `https://demo.150.chat/home.html`。本轮将原教学体验入口改为项目介绍和可点击预制样例，主站和账号版游客功能保持原有行为。

## 内容与样例

页面以登辉申请书的步骤级诊断和方法迁移为主线，介绍研究问题、统一内容结构、六阶段训练、未来能力、计划进展及团队。只公开项目和团队/导师姓名，不发布原 PDF、学号和联系方式。

四组样例均明确标注预制：

- 分步解析使用已有三道近年高考题及本项目准备的解析，支持分问、标准/详细推理、五维步骤难度及求解/校验/整理说明。
- 作答诊断用 2024 上海卷第 18 题第 (1) 问，自拟学生遗漏对数真数条件的作答，说明怎样由 x>1 与 x<2 得到 (1,2)。没有虚构学生得分或已测准确率。
- 几何演示用自拟正方体平行截面，参数帧由已有几何编译器校验；可播放构造、旋转、调整截面高度。无 WebGL 时明确降级为文字说明，并禁用不可用的参数控制。
- 套路图谱使用完整的 288 条参考目录及已有易混淆关系，支持筛选、搜索、缩放、平移与键盘查看。固定目录不代表所有条目已成为正式母题。

教师端/教研端、试卷质量与整卷作答报告、手写笔与 App、RAG/MCP/专用 Agent、Benchmark 均以图文研究规划介绍。申请书中的 95% 首次错误定位、90% 样本评分偏差不超过满分 5%、100 题目族/300 份作答及 20% 封存测试集，是研究目标而非实验结果。页面的 23,255 道原题仅指 2026-10-13 本机采集库存，未表述为已完成人工审核的正式教学库。

## 运行边界

`backend.showcase:app` 只提供公开资源白名单，旧 HTML 跳转到对应章节，所有业务写入/模型 API 返回 404。它不导入主人应用、不读主人题库或配置、不创建访客会话。只有回环地址可以访问维护接口，且拒绝转发来源头。

健康响应为 `ok=true, mode=demo, demo_mode=showcase, ai_enabled=false`。同步脚本兼容旧体验模式，保留维护、备份、回滚流程。部署账号仍是 `studydemo`，端口仍是 8001；原体验数据和旧连接快照保留，展示服务不读取它们。

## 本地预览与验证

```bash
.venv/bin/python scripts/run_demo.py --port 8301
```

打开 `http://127.0.0.1:8301/home.html`。数学与几何依赖均已放在仓库本地，不需要外部 CDN。预制素材由 `scripts/build_showcase_data.py` 生成，生成器仅读取已提交的例题和参考目录。

测试包含：资源白名单、路径/转发头边界、无数据库/会话/收费模型、维护接口、原游客/账号回归、样例数学与引用、真实 Chrome 的四组交互、键盘切换、手机无溢出和 WebGL 降级。

## 发布顺序

先在 c9a8d37 版本完成现有 23,255 道题与审核账本的导入；旧数据包导入器精确检查该提交。展示版离线发布包会在停站前核验这批题目和审核的统计，未确认导入则退出。之后沿用完整 Git SHA 的双站同步，由用户在 Workbench 手动启动。本轮代码包无需包含原题库、审核数据库或申请书 PDF，也不需要重新下载 Python 依赖。
