# 项目演示工作台

公开入口保持 `https://demo.150.chat/home.html`。展示版继承原站“成为数学高手”的名称、灰白工作区、侧栏、老师主题、步骤排版、图表、聊天动画和几何画板，使用固定公开样例与浏览器演示状态。

## 展示流程

左栏提供十个视图：项目总览、分步解析、作答诊断、提示与方法迁移、几何动画、原题与审核、套路图谱、题库组卷与巩固、研发进展、研究方案与团队。演示路线共十四个操作片段，可播放、暂停、跳转和重置，也可自由操作。首页进入时自动播放原书写标题的全屏开屏动画，可立即跳过，约2.6秒后进入工作台；减少动效设置下直接进入。首页顶部不放大幅书写图。

- 分步解析保留三份已有高考题，采用原站分问和步骤卡片，支持详细推理、五维难度柱状图与整体雷达图。
- 作答诊断展示遗漏定义域的人工预制作答、首次错误及反馈依据，可对照修正后的过程。
- 提示流程有提示、错误、正确三个固定分支，完成当前步骤后进入下一步；自拟对数变式展示同一方法如何检查新真数条件。所有对话明确标为预制，不接受自由输入后冒充实时推理。
- 几何有二维椭圆焦半径、三维三棱锥中点垂线、正方体截面三个自拟构造，使用现有校验器和画板。初始显示题设图，点步骤释放对应辅助构造；支持旋转/平移、缩放、重播及截面参数播放。无 WebGL 时保留文字并禁用不可用控制。
- 原题与审核通过三份固定样例展示自制题图、完整题页、原答案、来源和主/辅助套路建议。建议是人工编排的演示材料，不是主人真实审核记录。确认按钮只改变当前页面演示状态。
- 套路图谱沿用三栏目录、画布和详情布局。固定288项/12板块，关系与参考目录完全一致；每页最多12个节点，可搜索、翻页、拖动或键盘微调。布局仅存于此浏览器的 `study-showcase-layout-v2`。临时新增条目仅在当前演示中存在，没有自动生成的联系，重置恢复。
- 题库采用六份固定条目，可选择题目、切换学生/教师预览并在浏览器打印当前选题。另有核验过的两题对数方法学生/教师PDF可下载，明确区分固定下载卷与当前选题预览。日历使用示意安排。

## 研发进度与研究边界

进度固定为2026-10-13本机快照：23,255道去重原题、61来源、23,536条出处；288项参考套路；全量批次23,138条处理成功、117条错误，17,005条有主套路建议，覆盖278个目录条目。当前批次人工确认数为0，仍待人工审核；这些不是诊断准确率、学习效果或服务器在线库存。

题图恢复、出处回看、匹配与复查、几何联动、图谱编辑与审核跳转、侧栏及备份可靠性均作为已实现进展介绍。服务器23,255题导入尚须核验。教师/教研端、试卷质量和学生整卷报告、手写笔/App、RAG/MCP/专用Agent、独立Benchmark继续以图文研究规划介绍。95%首次错误定位、90%评分偏差不超过满分5%的比例、100题目族/300份作答/20%封存测试，均为申请书目标。

## 技术边界与素材

`backend.showcase:app` 只提供精确资源白名单，旧页面转到对应视图。业务读写、解题、任务、教学与上传API均关闭，不创建游客数据库，不读取主人实时库、密钥或配置。维护接口只接受真实回环来源。健康标识仍是 `mode=demo, demo_mode=showcase, ai_enabled=false`，原账号版游客和主人应用继续由原实现提供。

原站公共样式、雷达/柱状图、几何库、字体和数学资源都在本地。素材由 `scripts/build_showcase_data.py` 生成，仅读取公开预制题和参考目录。PDF可用 `scripts/build_showcase_papers.mjs` 与本机Playwright/Chrome从固定样例重新生成；服务器无需Node或PDF生成环境。

视觉与交互依据已安装的 Anthropic `frontend-design` 和 Vercel `web-design-guidelines`，继续使用现有HTML/CSS/JavaScript。技能来源与内容摘要记录于 `docs/showcase-design-sources.json`，不把技能本体或私人PDF上传到部署站。
