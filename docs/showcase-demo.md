# 项目演示工作台

公开入口为 https://demo.150.chat/home.html，正式站入口为 https://150.chat/。展示版沿用原站侧栏、老师主题、解析排版、难度图和几何画板。

## 本轮行为

- 三道高考题按梁梁、韬韬、雪峰、鸡分别实际运行 Solver → Verifier → Formatter，展示十二份结果。切换老师会切换标准过程、详细解释与步骤难度。梁梁侧重关键得分点，韬韬解释等价关系，雪峰检查条件与端点，鸡逐行展开。
- 题库导出原网站已入库的33题，保留原题、题型、知识板块、来源、答案与完整步骤。支持搜索、筛选、分页、勾选组卷、学生/教师版和打印。未接入23,255题原题池。
- 教学区直接呈现师生对话，按钮使用具体回答。四位老师各自保存当前步骤、提示、回答、变式和聊天内容，刷新后恢复；聊天框中的“重新开始”重置当前老师的本题对话。变式也有对应的真数条件、单调性和交集三步。
- 删除旧引导框、路线播放栏及重复的自我说明，保留必要的功能名、题源、研究规划和目标标签。全屏书写开屏仍可立即跳过，约2.6秒后自动结束，减少动效时直接进入。
- 题库列表与详情同时可见，手机按单栏显示；手机教学优先显示聊天区。旧页面仍转到相应视图。
- 展示站增加正式站链接；公开入口及相关界面使用“开发者登录”。账号版正式站的游客由后端强制只读，禁止编辑、上传、任务、解题、教学生成和付费AI请求；即使共享AI环境变量开启也不会开放。开发者及已有个人账号的原权限保持原实现。

## 数据与构建

`frontend/showcase/pipeline.json` 是实际模型管线的最终结果和阶段输出。`scripts/run_showcase_pipeline.py` 使用本机已配置的DeepSeek；构建日志与中间输出留在忽略目录 `.runtime/showcase-pipeline`，不调用题目入库提交。

`frontend/showcase/question-bank` 是33题的公开JSON导出。`scripts/build_showcase_bank.py` 以SQLite只读连接选择题目与解析字段，不导出账号标识、学习记录、查看时间、联系方式、设置或密钥。展示服务只读取导出的文件，运行时不连接主人数据库。

`backend.showcase:app` 提供明确资源清单、题库清单内的JSON/图片及维护接口；业务写入和AI接口不开放，不创建游客数据库。数学、图表和几何依赖均为本地资源。健康状态为 `mode=demo, demo_mode=showcase, ai_enabled=false`。

## 检查与部署

本机预览：`.venv/bin/python scripts/run_demo.py --port 8302`。

检查包含：十二份管线结果、三十三题完整性、只读导出、四老师切换、聊天刷新恢复与重置、变式、组卷、几何、图谱、桌面/手机、键盘、减少动效、WebGL降级和网络请求边界。游客只读测试在共享AI开关开启、主人密钥存在的条件下验证拒绝操作。

安装及同步在停站前核验全部展示资源和题库清单。依赖未变化；发布包固定本地Git提交并保留备份、双站健康检查及失败回滚。旧23,255题导入器限定c9a8d37，本轮包继续在停站前核验旧导入完成情况，避免升级后无法使用旧导入器。具体包名、校验值和Workbench命令以本轮发布说明为准。
