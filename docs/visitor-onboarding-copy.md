# 游客逐步体验引导

此稿对应当前游客页面。主人的页面保留原有功能。

## 开场与主线

**一起体验一次学习过程**

先解一道题。等待时可以看题库、组一张卷，再体验集合首关。结果准备好后，回到解析并试着自己作答。所有修改都只保留在本次体验中。

主线：**提交解题 → 等待时看题库 → 组卷 → 集合首关 → 回到结果 → 手把手教学**。

每次只显示一个提示，实际控件以蓝色边框标出。点击控件、收到任务结果或显示作答反馈后继续；纯说明使用“知道了，继续”。进入演示首页后自动开始教程，未完成前提供“上一步”“跳过这步”，不提供提前退出；完成后可继续体验或直接前往 150.chat。首页与顶部可以重新开始引导；重新看引导不会清除数据。顶部“重新开始”用于清除本次体验并恢复演示题库。

**任务开始后**：

解题正在进行，页面可以继续使用。请点击“个人题库”，查看已经准备好的题目与解析。

跨页后任务继续执行，任何页面都能查看后台任务与完成提示。完成后由游客主动回到解答，不强制跳转。例题使用已准备解析时明确标注来源；自定义题不替换成另一道例题。

## 等待时体验题库与组卷

1. 点击一张演示题卡片，查看题干和已有解析。刚才的新题完成后也会保存在本次题库。
2. 点击“返回列表”，使用对应卡片的“加入组卷”按钮。
3. 点击“前往组卷”，切换到“教师版”查看答案与解析。
4. 认识试卷预览；可修改标题、顺序、答题空间。导出不是必做步骤。

## 集合首关

闯关保留 12 个板块的目录顺序，集合与逻辑用语在最后，默认进入该板块。集合现有 21 项方法主题；其他 11 个板块当前均为 0，显示“尚未完成”。

首关：**集合的概念与性质**。

- 确定性：能明确判断给定对象是否属于集合。
- 互异性：重复书写不会增加元素个数。
- 无序性：元素的书写顺序不改变集合。

两个实际判断及即时反馈：

1. “很大的数”能构成集合吗？——不能。“很大”没有明确标准，不满足确定性。
2. {1, 2, 3} 与 {3, 1, 2} 是同一个集合吗？——是。元素相同，顺序不改变集合。

回答两道判断后显示“已体验 2 / 2”，可返回路线。本次回答和体验进度保留在当前游客会话。这里不会进入套路循环，不把查看或答对两题计作掌握、通关或解锁。其余关卡显示“尚未完成”。

## 回到结果与教学

完成提示保留任务入口；点击“回到解答”再查看结果。未完成时继续浏览；失败时可返回解答重试。

请展开一个详细过程。标准过程方便回顾，详细过程帮助理解推理。如果结果来自已准备的演示解析，页面会明确标注。

请点击“手把手教学”。保持默认老师并确认开始，教学问题准备好后，在回答框写下想法，再点击发送。不会时可以输入“给我一点提示”。收到实际反馈后完成这段引导。

结束提示：

你已经体验了解题、找回解析、组卷、集合首关和自己作答。可以继续教学或自由探索，也可以点击“前往 150.chat”；首页可以重新看引导。

## 尚未完成的页面

## 页面衔接

引导状态按游客会话保存，跨页和刷新继续；教学新标签页同步同一引导进度。实际交互事件包括例题选择、解题任务提交与完成、打开首关、两次概念判断、返回路线、教学反馈。引导只描述页面中存在的控件，不自动提交 AI 请求或导出文件。
