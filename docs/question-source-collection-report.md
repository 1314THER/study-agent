# 在线找题功能交付记录

核验日期：2026-10-11（北京时间）。入口为 **原题池 → 题源与导入 → 在线找题**。

## 已落地的功能

- 网页提交后台采集任务；切换页面后继续，重新打开可恢复进度并查看上次报告、缓存命中、失败页和未完成题源。
- 独立命令 `python3 scripts/collect_question_sources.py --years 2025 2026 --concurrency 20` 完成发现、下载、转换和原题池导入。默认年份随最近两年更新。
- Hugging Face JSONL 与公开免费 PDF／DOCX 两条获取路线；专题目录一并搜索。原答案不作为条件，不调用解题 AI。
- 原始文件、卷名、出处、文件哈希、页码、题号、题图和 JSONL 保留。结构化数据有固定版本、下载镜像、哈希核验及离线入口；不能获取新版本时明确报告并复用已验证快照。
- PDF 原生文字优先，乱码文字层和扫描页调用 DeepSeek Flash。进程内最多 20 个共享请求槽，PDF 读取与渲染串行。成功页缓存、失败页重试、文件运行锁及分批写库支持断点续跑。
- 先分卷再切题，页脚与答题须知不会变成题目，答案按同卷题号匹配。题图参与去重；重复提取保护人工修改。
- 最低年份 2016 统一用于导入、上传、重试、解析准备及确认入库。未知年份保留；题干数字和下载发布日期不作为年份依据。

模块是 `backend/question_source_collector.py`，网页 API 是 `POST /question-pool/collect`、`GET /question-pool/collection`，后台任务类型为 `pool_collect`。题源登记在 `config/question-sources.json`；具体命令及读取方法见 [agent 指南](question-pool-agent-guide.md)。

免费文件来源为 [武汉教育资源网](https://www.wh111.com/shuxue/jingxuanshiti/gaozhongshuxue/gaosanshuxueyuekao/)，结构化源为 [gaokao-related-math](https://huggingface.co/datasets/cheese233/gaokao-related-math)。这两条自动路线没有全国全集或持续更新频率的承诺。

没有取得的 119 个链接保留在报告中：110 个未标为免费，8 个下载返回网页或不支持的文件，1 个没有可读取的附件入口。高三专题目录已扫描，本轮没有另行取得免费专题附件；专题索引来自已获得的完整试卷。公众号只登记了可见线索，尚未验证出稳定可自动获取的完整题库。概率解答题候选也不能全部视为与 2025 年全国二卷第 19 题同难度。

## 当前库存

清理后原题池为 18,048 道，本轮新增 5,207 道独立候选，当前为 **23,255 道、23,536 条出处**。公开 PDF 历次核验后累计保存 57 份卷的 1,083 条候选；其中少数在更严格的最新边界核验中仍需复核，保留为未确认候选，不自动进入正式题库。

正式题库仍为 **33 道**。当前来源比例和板块标签比例见 [来源与导入](question-pool-sources.md)。15,696 道没有可靠年份，按约定保留；不把数据集创建时间当作它们的题源年份。
