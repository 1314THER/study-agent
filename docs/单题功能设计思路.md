## 1. 总体思路

**AI 解题是单题功能的基石，结构化步骤是其他单题功能共用的基础。** 新传入的题目首先经过三阶段 AI 解题流水线，形成包含参考答案、解题步骤、知识点和难度信息的解析。后续批改、教学与出题都围绕这份步骤结构展开；已有解析的题目可以复用解析。

```text
题目 → AI 解题流水线 → 结构化参考解析
                          ├→ AI 改题：对齐学生作答，定位错误步骤
                          ├→ 手把手教学：逐步提问、检查、提示与推进
                          └→ AI 出题：按步骤与参考题生成针对性练习
                                             ↓
                                 新题再次进入解题流水线校验

学生手写作答 + 笔迹时间线 → 步骤批改与过程复盘
                                   ↓
                 错题与题库：步骤错因标定、查找、题单与组卷
```

这里“AI 改题”指批改学生作答；“AI 出题”包含围绕参考题或母题生成变式。功能之间的共同点是：把解题过程显式拆成可以引用、判断和训练的步骤，使模型的判断有明确对象。

## 2. AI 解题：为所有单题功能准备结构化依据

### 2.1 设计目的

相比仅要求通用模型自由生成一段答案，项目使用预先定义的步骤体系约束解析的组织方式，力求让输出更可控、更有结构、更符合试题的过程表达要求，也更易阅读和理解。

步骤体系规定可复用的解题操作，具体题目再选择、组合这些操作并填入推导与计算。它不意味着所有题目只能采用同一条解法。

### 2.2 三阶段职责

| 阶段 | 主要任务 | 对后续功能的意义 |
| --- | --- | --- |
| Solver：解题 | 理解题目，给出完整解答，识别题目所属板块或校验模板 | 先获得数学解法，供后续拆分与检查 |
| Verifier：校验与结构化 | 检查解答，按题目或小问分块，再拆成步骤，关联知识点，整理标准过程与详细过程 | 建立批改、教学和仿题可以共同引用的步骤结构 |
| Formatter：整理与输出 | 检查一致性，整理为约定结构，补充步骤难度信息 | 形成前端与后端可以稳定消费的参考解析 |

步骤的标准过程用于呈现关键推导与得分内容，详细过程用于帮助理解。格式与结构约束使系统可以按步骤展示、引用和处理解析，而不必反复从长篇自然语言中猜测其组织方式。

## 3. AI 改题：依据步骤定位学生在哪里出错

### 3.1 从整体判断转向逐步对照

输入原题、结构化参考解析和学生完整作答，将学生作答中的内容对应到参考步骤，判断每一步是否完成、是否数学等价、是否存在关键遗漏，并定位具体错误。

设计目标是让系统能够说清楚“哪一步、哪段作答、什么问题”，为后续教学与训练提供依据。例如，学生已经正确列式，但在化简时出错，应定位到化简步骤，而不应仅凭最终答案错误就推断学生不理解列式所用知识。

### 3.2 “避免 AI 去猜”的含义

步骤结构为判断提供对照对象，学生作答提供证据。应将可观察的错误与对错误原因的解释分开：

- 学生写出错误等式，可以指出等式与前一步不一致。
- 学生没写某一步，只能首先认定该步骤缺失；不能直接认定其不会相关知识。
- 学生使用另一种正确解法，应独立判断其数学正确性，不能因不符合参考路径就判错。
- 证据不足时，应保留判断并通过追问或补充练习核实。

因此，“精准定位、避免猜测”是通过步骤和作答证据追求的设计目标，是否实际降低误诊率，需要与教师标注及对照系统比较。

### 3.3 引入手写笔和时间戳：从最终卷面看到作答过程

面向无纸化学习场景，计划通过平板和手写笔记录作答，将每一笔及修改操作与发生时间关联。批改时除最终卷面外，还能查看学生按什么顺序书写、在哪里停顿、何时回到前一步修改，以及错误是否被学生自行纠正。

**目标是把“哪一步出了什么问题”与实际发生的作答过程对应起来。** 例如，最终答案虽然正确，时间线仍可能显示学生先列错式、随后划去重写；最终答案错误时，也可以区分最早出现的错误与后续沿用错误结果的推导，避免把同一错误的传播重复归因为多个独立能力缺陷。

应保留以下过程信息，供批改与学生复盘共同使用：

| 信息 | 设计用途 |
| --- | --- |
| 笔迹坐标、笔画顺序、相对时间 | 重建书写发生的位置与先后，关联到具体步骤 |
| 擦除、撤销、重写与回到旧区域的记录 | 保留最终卷面中可能已经消失的尝试，观察自我修正 |
| 作答中间状态 | 按时间回放，比较某次修改前后的内容 |
| 提示、查看答案、切题与暂停等事件 | 区分独立作答、获得帮助后的修改以及离开任务的时间 |
| 步骤与笔迹片段的对应关系 | 从批改结论跳回具体书写区域、相关时段及修改版本 |

时间应以同一作答会话的连续相对时间为主要依据，保留中断、恢复与事件先后，不能只使用上传或保存时间替代真实书写时间。压力、倾角等信息可以按设备能力附加，首期不作为必需输入。

### 3.4 时间如何关联步骤，怎样辅助诊断

自由手写时，物理笔画、页面上的一行文字与逻辑解题步骤不严格对应：学生可能先算后补理由，也可能多次返回同一步。因此，一步可以关联多个不连续时段；同一段书写的步骤归属不确定时应允许待确认，不强行把整页按行或按固定时间间隔切成标准步骤。

设计流程为：按时间和空间组织笔迹片段，结合片段内容、前后卷面与参考解法，识别其所完成的数学操作，再对齐到相应步骤。短期可允许学生圈选确认或修正对齐结果；替代解法应保留自己的步骤路径。

复盘中区分实际书写时长、落笔间隔、某步骤首次出现到最后修改的跨度，以及整题经过时间。步骤之间的停顿不一定能明确归属到其中某一步；不同步骤的修改时段也可能交错，不能简单累加时间跨度作为整题用时。

时间信息用于发现值得核实的片段，判断仍以内容为依据。例如，“在化简前停顿较久，随后连续两次改写同一等式”是可观察事实；“不会化简”“注意力不集中”是需要更多证据的解释。停顿也可能是读题、心算、检查或暂时离开，写得慢不能直接判为不会。

在首期设计中，优先支持提交后的过程回放与批改复盘。实时教学干预可在此基础上研究，但不能因为一次停笔就立即打断学生。

### 3.5 缺少专门训练数据时怎样起步

当前缺少的是与本项目知识点、步骤词表和错因口径对齐的真实过程标注，不是必须从零训练一个笔迹大模型才能记录时间。可以先用现有多模态模型与规则构建可复核的过程分析，再逐步积累数据。

1. **先采集、能回放。** 保留原始笔迹与修改事件，让学生可以自行复盘；这部分无需先训练诊断模型。
2. **再做辅助对齐。** 结合时空分组、关键状态图像和已有步骤参考，由现有模型提出步骤对应及错误位置，交由学生或教师确认。时间阈值只是分组工具，应校准，不能直接当成卡顿判据。
3. **积累少量高质量标注。** 标注步骤对应的笔迹和时段、首次可观察错误、自行改正、求助、替代解法及无法判断的情况；错因需注明证据来源，不能用 AI 自己生成的原因直接当作真实标签。
4. **先验证时间有没有增益。** 在同一模型、相近调用预算下，对比“仅最终卷面”“增加时间顺序与中间状态”“再加入停顿和修改事件”。评价步骤对齐、首错定位、无依据归因、自我修正识别与学生复盘效果，并按学生和题目划分数据，防止同人同题泄漏。
5. **有证据后再考虑训练。** 先形成可用的评测集，再根据错误类型决定是否训练或微调步骤对齐、片段分类等组件。合成笔迹可以测试回放和流程，不能代替真实学生思考过程的数据。

相关研究与数据可用性见第 8 节。上述内容是设计路线，尚不表示已完成带时间戳笔迹的自动诊断。

### 3.6 主动诊断：围绕待验证原因安排补测

项目已有学情诊断、验证目标与新题复测关联能力，见 [当前实现能力与名词数量](当前实现能力与名词数量.md)第 9 节。它把错误进一步转成需要核实的问题，而不是只输出错因标签。

设计上，发现一个错误后，先列出可区分的解释，再安排有针对性的短任务。例如，分别通过条件辨析、独立列式和计算片段，检查概念、方法与执行；必要时比较限时与不限时表现。记录结果是否支持、反驳或尚不能区分某个解释。

已有链路以规则诊断和复测关联为主；自动生成区分性小题、依据回答调整下一题、达到证据或负担边界后结束诊断，是进一步增强方向。不得将当前关联一条练习记录直接等同于所有自动流程均已实现。

## 4. 手把手教学：强步骤相关的教学 agent

### 4.1 让教学行为对应明确的学习状态

只依赖自由对话时，教学 agent 可能无法清楚区分学生究竟掌握了什么、在哪个环节需要帮助。本项目让教学过程与解题步骤紧密关联：每一步都有明确任务、预期结果和学生实际回答。

基本教学循环为：

```text
提出当前步骤的问题 → 学生尝试 → 检查本步回答
                                  ├→ 正确：进入下一步
                                  ├→ 部分正确或错误：反馈并继续尝试
                                  └→ 不会：补充提示或更细的引导
```

这种结构使系统有机会掌握当前题中各步骤的表现：学生是否独立完成、尝试了几次、是否需要提示、是否看过答案、是否仍有具体错误。后续教学可以据此选择继续讲解、补充前置知识或安排步骤专项训练。

### 4.2 区分完成教学与掌握能力

学生在提示下完成一步，说明其完成了这次学习任务；在新题中独立完成同类步骤，才是更强的掌握证据。设计上应区分独立答对、提示后答对、看答案后完成、跳过与尚未完成，并通过后续练习核实掌握情况。

步骤表现还可以沿“步骤依赖知识点、套路由步骤组成”的关系组织后续训练。但一次步骤错误并不能直接证明某知识点没有掌握。

分级提示与提示逐步撤除，以及解释、探究和多解法任务，暂列进一步研究，见 [待深化功能研究](待深化功能研究-提示干预与可靠接入.md)；不据此认定当前教学流程已具备这些完整能力。

## 5. AI 出题：以步骤和参考母题约束生成

### 5.1 把开放出题转为有参考结构的变式设计

通用出题 agent 需要从教学要求出发，同时确定知识目标、解题路径、题目条件与难度。本项目的出题通常已有步骤参考，并且很可能已有母题或其他参考题，因而可以沿既定解题结构生成变式，或专门强化学生出错的步骤。

设计输入包括目标步骤、参考题及其解法、相关知识点、目标难度，以及学生已暴露的错误。输出应是能实际训练目标步骤的新题及其经过校验的答案和解析。

### 5.2 如何理解“只需要解决题目有解即可”

当教学目标、步骤路径和母题结构已经确定，出题最主要的剩余工作可以集中在构造合理条件，并验证新题确实能解出来。这是本项目缩小出题搜索范围的关键思路。

**这以其他教学约束已经满足为前提。** 参照用户提供的教育出题示意图，仍需要检查四件事：

| 要求 | 在本项目中的含义 |
| --- | --- |
| 能解 | 条件充分、无矛盾；对要求唯一答案的题目，答案应唯一 |
| 解对 | 新题的答案与过程正确，不能沿用改题前的旧答案 |
| 对目标 | 新题仍能训练预定知识点与步骤，未意外换成另一类方法 |
| 适合学生 | 所需知识、计算量与非常规程度适合学生当前学习阶段 |

例如，同样采用一元一次方程的列式与求解步骤，可以改变购买数量、优惠金额与付款金额生成应用题；仍需确认条件有意义、能够得到合理答案，并且没有引入未学方法。

生成后的题目应重新进入 AI 解题流水线，得到实际解法，再检查实际步骤与目标步骤是否吻合。生成时声称采用某步骤，不等于新题实际需要该步骤。

## 6. 错题与题库系统：让学生围绕步骤自主复盘

### 6.1 按步骤标定错因，保留每次作答依据

错题记录应能从整道题下钻到具体步骤：标明错误步骤、观察到的问题、作答证据、错因标签与学生自己的说明。接入手写时间线后，还应能回到对应笔迹片段与修改过程。

AI 可以提出错因建议，学生可以确认、补充或纠正；应保留建议与确认的来源。一个步骤可有多个问题，同一种错误也可在不同题目中重复出现。记录应关联到某次作答，复测时另记结果，避免学生后来答对就覆盖此前错误过程。

题库保存题目和可复用解析，错题记录保存学生在某次作答中的表现。同一道题可以多次作答、多次复盘，也可以服务多个训练目标。

### 6.2 查找与整理：从“做过哪些题”转向“哪一步需要练”

支持按步骤、错因、知识点、套路、题型、难度、来源及作答状态组合查找，允许学生将结果整理为个人题单。例如：

- 查找“建系之后求法向量”这一步曾出错的题目，比较每次错误的具体位置。
- 查找同一步骤下的计算错误，区分偶发失误与多次出现的问题。
- 查找“看过答案才完成、尚未独立复测”的题目，安排下一轮练习。

查询条件还应区分“题目含有这个步骤”和“学生在这个步骤上出过错”，并允许查看同类步骤的正确作答作为对照，避免只看错误记录就认定一直不会。

### 6.3 组卷与复测：把复盘发现变成可执行练习

学生可以把筛选后的题目加入题单或组卷，选择原题重做、同套路变式或某步骤专项练习，并结合知识范围与难度组织训练。卷后仍按步骤查看表现，与之前作答对照。

原题重做可以帮助检查订正与熟悉程度；判断是否能够独立应用，应增加未见过的同类题或变式，并保留是否获得提示、是否查看答案等信息。

### 6.4 面向学生的复盘路径

```text
找到错题 → 查看错误步骤与原始作答 → 回放停顿及回改片段
        → 确认或修正错因 → 查找同类步骤题目 → 整理题单或组卷
        → 独立重做与新题复测 → 比较新旧步骤表现
```

这里的重点是让学生能自己看见、解释和核实问题，再选择下一次训练，而不只是收集一份“做错过的题”。没有笔迹时间线的普通作答，也应能够使用步骤错因、查找与组卷功能。

## 7. 单题功能与复盘系统怎样衔接

AI 解题建立参考步骤；AI 改题将学生表现及可用的笔迹时间线对应到步骤；手把手教学围绕薄弱步骤提供引导；AI 出题把训练需求变成新的练习。错题与题库系统承接过程记录、步骤错因和练习材料，使学生可以查找、组卷并自主复盘。新题的独立作答又提供新的步骤证据。

项目的设计价值在于复用同一套步骤表示，使错误定位、教学动作和练习目标能够具体对应。步骤标签本身不能代替数学判断，四项功能也都依赖上游参考解析的质量。

| [Stepwise Verification and Remediation，EMNLP 2024](https://aclanthology.org/2024.emnlp-main.478/) | 定位学生推理错误，并用验证结果指导反馈 | 本项目同样强调先有错误定位依据，再给反馈；可比较共享步骤词表是否改善定位、作答对齐与后续训练选择 |

本项目可以重点验证：在相同基础模型下，加入显式步骤结构，是否比只给原题与自然语言答案更容易准确定位错误、控制教学推进，并生成命中目标步骤的练习。这是可检验的设计假设。

### 8.1 时间戳、手写过程与卡点诊断：已有相近研究

检索日期：2026-10-25。以下优先使用论文原文、作者项目页和数据官方说明。数据条数是外部研究规模，不是本项目现有数据量。

| 工作 | 做了什么 | 与本项目的关系及可借鉴之处 |
| --- | --- | --- |
| **CogChain：Automatic Modeling and Analysis of Students’ Problem-Solving Handwriting Trajectories，AIED 2025，港科大团队** | 从 25 名高中生采集数理化考试的 87,679 段笔迹轨迹，包含坐标、时间与落笔状态；按时间分组，再用多模态大模型分类并展示过程 | 是“数字笔＋时间＋大模型分析解题过程”的直接先例。其主要分类包括方程、草图、标记等，不能直接等同于本项目具体数学步骤及错因；可进一步研究与步骤词表的对齐。[作者版论文](https://shenleixian.github.io/pdf/iPen.pdf)、[正式发表信息](https://researchportal.hkust.edu.hk/en/publications/automatic-modeling-andanalysis-ofstudents-problem-solving-handwri/) |
| **Identifying Students’ Stuck Points Using Self-Explanations and Pen Stroke Data in a Mathematics Quiz，ICCE 2021，京都大学团队** | 以评分量规的步骤为参照，结合学生自我解释和笔迹行为，研究操作时间、操作顺序与卡点识别的关系 | 与“步骤＋时间＋学生解释”很接近，也支持让学生参与确认错因。论文使用统计分析与逻辑回归，仍提出扩大样本和自动识别的后续任务，不能将其概括为已经可靠读懂学生思考。[会议原文与摘要](https://library.apsce.net/index.php/ICCE/article/view/4287) |
| **Exploring Visual Access and Proactive AI Tutoring for Handwritten Mathematics，2026-10-19 预印本，CMU 等团队** | 让辅导模型通过手机摄像头观察纸上作答；研究涉及 117 名成人和 255,984 张带时间戳图像，关联辅导对话与干预决策 | 可研究过程图像对错误定位、提示时机的作用；它是相机图像序列，不是逐笔坐标，也不是中国高中数学步骤标签。[论文](https://arxiv.org/abs/2610.26411v1) |

这些工作说明方向已有基础。本项目可进一步检验：把笔迹时间线连接到明确的数学步骤、具体错误证据和学生可操作的复盘训练，是否比只看最终卷面或一般书写行为分类更有效。时间线提供过程证据，不等于直接记录了学生的内部思维。

### 8.2 哪些数据能用，哪些仍存在缺口

| 数据或资源 | 当前能确认的获取状态 | 能支持什么、不能替代什么 |
| --- | --- | --- |
| **CogChain 的高中生笔迹过程数据** | 本次在论文和学校发表页中未确认到公开数据下载入口；不能因论文报告采集规模就视为可下载训练集 | 对任务与采集设计参考价值高；如需数据，可再向作者询问获取条件。本次未联系作者 |
| **ICCE 2021 的卡点研究数据** | 会议页面未提供可确认的数据集下载入口 | 可参考量规、自我解释与行为特征的组合方式；尚不能计入本项目可直接使用的数据 |
| **2026 手写主动辅导项目** | 论文写明发布数据，但截至本次核查，[作者仓库](https://github.com/nachiketdk/proactive-ai-tutoring)的 README 仍表示计划未来数月发布，并可联系作者讨论提前访问 | 是值得跟进的过程数据来源；当前不能写成已取得完整数据，也不能用图像时间戳替代笔画轨迹 |
| **Google MathWriting** | [官方仓库](https://github.com/google-research/google-research/tree/master/mathwriting)提供完整包、样例包和读取示例；[数据说明](https://github.com/google-research/google-research/blob/master/mathwriting/archive_readme.md)确认含空间坐标与相对时间，数据采用 CC BY-NC-SA 4.0 | 可用于公式笔迹识别和时序读写实验；内容是照写给定表达式，并非学生自由解题，没有步骤掌握、停顿原因与错误诊断标签；合成样本的时间也不能当成真实思考用时 |
| **CROHME** | [官方数据发布页](https://zenodo.org/records/8428035)提供公式识别数据；[官方格式示例](https://www.isical.ac.in/~crohme/data2.html)列出 X、Y 通道 | 可用于公式与符号识别；不能因使用 InkML 就认定每个样本含真实时间通道，需检查具体文件，更不能当作解题卡点数据 |

**因此，可获取的公式笔迹数据与相近的过程研究都存在，但“真实高中数学作答＋笔迹时间线＋本项目步骤对齐＋经核实错因”仍是本项目需要逐步建设的数据。** 合理起点是先实现可回放、可标注、可人工修正的工具，再验证时间信息的增益，而不是等待一份完全匹配的训练集。
