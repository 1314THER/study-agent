# 全国卷展示案例录制

本说明对应 `scripts/record_showcase_cases.py` 与公开的 `frontend/showcase/recordings.json`。主案例为 2023 年新课标全国Ⅰ卷第 17 题，补充案例为 2025 年全国一卷第 16 题。

## 来源与边界

原题与参考解析复用已保存的正式 Solver → Verifier → Formatter 运行记录。新增批改、基线、教学及变式调用使用仓库中的正式业务函数和已配置模型 API，来源标为 `local_production_code`。这不是线上正式站 HTML 抓取，也没有写入主人的题库或个人记录。

六份学生作答及相应过程说明是预先构造的测试输入，不是真实学生样本或教师标注金标准。观察目标 `expected` 与模型实际结果分开保存，不能将预期描述渲染为模型诊断。

普通基线只接收题目与作答；同信息基线同时获得参考解析和可用过程说明。三种条件使用同一批改模型、思考强度和温度。基线提示词明确要求引用原文、处理替代解法、在证据不足时保留判断；不故意设置弱基线。

现有 `grade_prepared` 没有独立历史参数。录制器将有来源说明的过程信息附在作答文本后，并向同信息基线提供相同信息；这不代表正式批改链路已具备完整的长期状态诊断能力。

公开记录保留完整模型回答、请求文本、配置、运行时间、输入及结果摘要校验值。系统结果还保留后端结构检查后的返回值。没有设置未经教师确认的分值量规，因而不会把模型暂定分数包装成正式考试评分。

## 运行

只准备固定输入，不调用模型：

```bash
.venv/bin/python scripts/record_showcase_cases.py
```

显式运行全部录制：

```bash
.venv/bin/python scripts/record_showcase_cases.py --run
```

也可使用 `--only comparisons`、`--only teaching` 或 `--only generation` 分别执行。已完成及已失败的记录默认均不重跑，以免挑选性采样。若传输或解析故障需要补录，先保留旧记录及失败原因，再将相应任务恢复为 pending 后运行；不能为获得有利结果反复采样。

`--continue-teaching` 可在保留原有所有分支的基础上继续同一教学记录，增加新的完整学生作答。`--resume-generation` 只允许修复录制器跟踪故障后继续校验已经生成的同一候选，不重新生成或替换被数学检查拒绝的候选。

本轮录制中，一条已完成的同信息响应因并发文件覆盖而未保存，按相同输入补录；文件保存现已增加锁及新旧检查点合并。变式曾在子线程跟踪器处中断，原始候选及故障记录保留在 `previous_attempt`，修复后继续校验同一候选。上述补录为存储与跟踪故障恢复，不是依据模型答案好坏挑选重跑。

教学与变式使用临时工作区。运行所需配置仅暂存在权限为 600 的临时文件，结束后删除；密钥不进入公开 JSON、日志或版本库。

## 检查

```bash
.venv/bin/python -m unittest tests.test_showcase_recordings -v
```

检查固定输入、真实输出摘要、模型与温度一致性、比较条件、隐私边界和教学/变式返回记录。检查本身不会调用付费模型。少量案例只能说明机制和实际表现，不能据此报告诊断准确率提升、全面优于基线或真实学生学习增益。
