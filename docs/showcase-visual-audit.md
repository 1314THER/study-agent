# 展示站视觉与逻辑动效审核

审核日期：2026-10-26。范围：11 个主题、教学与技术两栏、窄屏、章节交接、研究对照、Safari 校徽。

## 修改前发现

1. 校徽采用 SVG 内嵌图片及滤镜，在 Safari 出现圆盘内纹样残缺。改用预生成的白色纹样透明 PNG，继续使用黑色背景。
2. 交接进度到 68vh 才开始，连线与标题又二次延迟；JS 硬编码 sticky 位置与 CSS 不一致。改用可见区域的几何位置提前驱动，保留自然滚动。
3. 交接动画同时受旧 reveal 规则和新滚动规则管理；统一为一个滚动控制器。
4. 灰色旧规则覆盖蓝色新规则，正向闭环误用红色；研究任务范围整体染红。统一白色主论点、蓝色本项目机制与联系、红色具体不足，范围介绍保持中性。
5. 标题、导航、卡片、连接与到达目标同时发光。去掉文字和整卡光晕，仅让传递节点和激活连接短暂亮起。
6. 两栏只会整体变色，没有可读的输入与返回关系。按最终反馈取消可见关联箭头和关联条；保留步骤选择时的对应技术说明。
7. 821–1199px 的 desktop override 写成后代选择器，无法覆盖旧窄屏规则，可能只显示一栏。修正 body 组合类选择器。

## 视觉约定

- 背景 #080808，内容面 #101114，重点文字 #f5f5f5，次要文字 #b6bbc5。
- 蓝色 #8ab8ff：本项目机制、关键产物、选中与激活的关系；白色加粗：主要判断；红色 #ff929c：实际错误、现实困难和明确的研究局限。
- 中性研究范围与已有研究的正向结果不染红。保存的模型原文只调整容器，不改写或增补强调标记。
- 双栏默认教学内容更宽，中间仅一条可拖动细线；隐藏旋钮与比例数字。手机用单栏标签或滑动切换，保留主题顺序。

## 验证项目

校徽透明度与真实 Safari 呈现；11 个交接在可见区域提前完成；821–1199px 两栏；手机单栏与对应定位；颜色语义、键盘、减少动态效果、刷新恢复；静态展示请求边界与原始输出一致性。
