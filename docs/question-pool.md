# 主人原题池工作流

启动现有应用后，在导航或母题看板点击“原题池”，也可直接访问 `/question-pool.html`。账号版仅主人可访问；私人本地模式沿用原有主人权限。无需 MCP。

## 本地采集结果

2026-10-10 已清理 13,001 道可靠证实为 2015 年及以前的旧题，保留 2016 年和未知年份。2026-10-11 接入高考真题汇编、HighMATH、Conic10K、229 套 2025/2026 结构化模考及免费 PDF 模考后，原题池为 **23,255 道题、23,536 条出处**。题干与题图共同用于去重。正式题库保留 33 道，采集结果先进入原题池，不自动运行解题 AI。下载文件和数据库在 Git 忽略的 `.runtime/` 内，迁移部署时需要单独带走这些数据。当前来源比例见 [来源与导入](question-pool-sources.md)。

集合与逻辑用语当前初筛标签为 1,080 道，实际文字候选以页面筛选结果为准。“板块覆盖与缺口”按现有套路列出缺母题和空变式槽位。数量只表示已接入来源的候选覆盖，不能证明教辅细类已经齐全；新增细类和代表题仍由主人确定。

## 筛选、解析和入库

1. 用板块、题型、题源、年份、关键词、完整性和处理状态缩小范围。默认显示全部题目，包括图形题和仍缺图的记录；完整性筛选可单独查看待确认、缺少题图或提取失败的题目。列表使用数据库分页，支持跨页多选。
2. 打开原答案、原解析、题图和出处。图形选项保留 A–D 标签，图片可点击查看大图；PDF 页在首次读取后缓存。文件题可回看原文件、起止页和题号；需补条件时修正题干，确认文字是否足以独立作答。无法判断缺图信息的题保持“待确认”。
3. 选择已有套路或填写新套路，指定普通题、母题、变式 1–3，并保存。现有槽位冲突会阻止入库，需改选空角色或其他套路。
4. 将题加入选择队列，点击“为选中题准备 AI 解析”。后台复用 Solver → Verifier → Formatter，解析保存在原题池；此步不会写正式题库。
5. 点击“预览入库”，对照原答案与 AI 答案。复用已有正式题时，还会显示保留的旧答案。冲突、缺答案或不能自动判断等价的题，需要逐题人工确认；失败项可单独选择后重试。
6. 点击“确认入库”。入库会追加独立出处，保留旧答案和已有母题关联；普通私有题以后晋升母题也不会丢出处。未确认的候选始终留在原题池。

选择队列、筛选条件和浏览位置会在当前账号的浏览器中恢复；原题修正、解析结果和入库进度保存在数据库。快捷键 `←` / `→` 切题，`S` 加入或移出选择队列。修改题干、答案或分类后，原 AI 解析失效，需要重新生成。

## 题源管理

“题源与导入”可上传 PDF、DOCX、TXT、JSON/JSONL、TeX 或扫描图片。OCR 复用现有图片接口，勾选后可能产生已配置 API 的用量；仅从公开仓库导入文字无需 OCR 或 AI。编号题支持跨页拼接，不能确定边界的片段保留待核对。

每个来源分别列出来源条目、独立题、完全重复、待核对、暂缓图形和失败数量。上传文件保留在私人目录，可以重新提取；相同来源、版本和定位重复导入不会重复新增。固定仓库导入命令见 [来源与导入](question-pool-sources.md)。

「题源与导入」中的「在线找题」可选择年份并启动后台采集。无需原答案；完整模考核验 19 题结构，导数与概率另外生成专题候选索引。原文件、题图和失败清单供回看，已成功下载及识别的内容在重跑时复用。具体题源、脚本和 agent 读取方法见 [在线找题指南](question-pool-agent-guide.md)。

各公开来源的题目发布范围目前均待核验。来源设置中的公开选项需由主人核实后更改；默认可保存普通私有题，不能直接作为共享母题或变式入库。公共目录发布时会排除待核验题目，并只包含允许公开的来源参考答案和解析；教辅原文件始终仅供主人核对。

默认数据库为 `.runtime/question_pool.db`，上传原件为 `.runtime/question-pool/files/`。设置 `STUDY_AGENT_DATA_DIR` 或账号工作区后，数据库和原件随工作区隔离。备份时一并备份正式题库、套路数据库、原题池和上传文件。

## 验证范围

清理前已用每页 100 道遍历原来的 31,049 道题，ID 无遗漏、无重复。清理后的真实汇编重导入跳过 13,479 条旧出处，新增 0 条；结构化新源和 PDF 采集缓存重跑也新增 0 条。120 项后端测试及前端流程测试覆盖旧年份过滤、断点续跑、20 并发限制、按卷匹配答案、重复导入、人工修订保护和主人权限。实际库存与未取得资料见 [交付报告](question-source-collection-report.md)。真实 AI 解析质量仍需在主人选出的题上核对。

原题详情使用本地固定版本的 KaTeX 显示公式，不依赖外部 CDN。公式分隔符、填空横线、分段函数、自定义排版宏和表格有专门适配；公式不能解析时保留原始 TeX 并提示核对，原题池数据库中的源文本不随显示转换而改写。2026-10-10 对全库扫描了 586,873 个公式片段，349 个片段在 KaTeX 下仍无法解析，涉及 340 道题；另发现 82 处未标记公式和 73 处未闭合公式分隔符。失败集中在源文本缺括号、`&` 等公式结构损坏或少见宏，保留原文供人工校对，不自动补条件。

## 2026-10-12 题图补齐

已下载 600 张高考汇编配图，复用模考缓存题图与 PDF 原页，并从题源 TeX 原码渲染 3 个程序框图和 12 个原表格。原先 1,130 道暂缓图形题中，1,077 道已恢复为待核对候选；53 道题源未提供可读取的图，仍保留缺图原因。总库存为 23,255 道、23,536 条出处。题目核对完整后，解析会携带图片及选项对应标签；附件缺失时阻止无图解题。未调用解题 AI。

已有套路审核批次可查看当前补齐的图片，快照题干、匹配结论与人工决定仍保留；源题版本变化继续提示重新核对。补图脚本先备份数据库，支持离线复查与重复运行：

```sh
python3 scripts/backfill_question_images.py --apply --concurrency 8
python3 scripts/backfill_question_images.py --apply --offline
```

本轮备份、逐题缺图清单、下载与渲染证据保存在 `.runtime/question-pool/image-backfill/`，TeX 表格预览保存在题源目录 `derived/`，`question-graphics.json` 记录渲染图的原题定位。迁移时连同整个题源目录和 `.runtime/question-assets/` 一并复制。重复离线补齐实测恢复 0、更新 0。
