# 教学愿景与社会价值

> 内容日期：2026-10-26（Asia/Shanghai）。状态：长期愿景。展示位置：数学 love 欢迎页之后、亮点章之前，作为第 1 章。

## 让每个学生，都能获得适合自己的学习支持。

从学生、教师、学校到社会，探索把及时诊断、针对性教学和持续跟进融入日常教育，让家庭不必为了补上日常学习缺口而额外补课。

围绕共同学习目标，根据每个人的实际表现，持续调整教、学、练、评。一次作答中发现的问题，接到后面的诊断、讲解、练习、复测、课堂调整和学校教研；每个环节知道前面发生了什么，也能检查后面有没有改善。

以下对照描述全部设想接入日常教学后的目标形态。传统一侧概括常见困难，许多优秀教师已在实践针对性支持；项目希望让这些做法更容易持续开展、覆盖更多学生。功能标签按当前本地实现区分已有基础、设计方案与研究方向；实际收益以真实使用中的独立表现、延迟保持和完整负担检验。

**社会目标：让必要的学习帮助更普遍可得，让家庭减少对额外补课的依赖。**

本章以四组完整对照展开：学生 21 项、教师 17 项、学校 17 项、社会 8 项，共 63 项。页面按“原来的困难 → 教学怎样改变 → 接续功能”串成可连续阅读的变化链，各分支默认显示前2项，其余通过展开按钮阅读；功能链接通往后续主题。无JavaScript时全文直接显示。2026-10-26界面修订：取消表格和红色强调，灰色交代背景，白色加粗突出实际变化，蓝色标记连接与功能入口。本文的对照表仅用于内容维护。

## 三个教学情境

### 一道导数题，怎样从错误走向对应帮助

求导正确，却把导数为负的区间写成递增区间。先描述观察，再用短任务核实原因。

1. **定位具体观察。** 保留已经正确完成的求导步骤，引用单调区间的错误作答，让学生知道需要检查的是哪一步。
2. **用短任务区分原因。** 先问导数符号与单调性的关系，再给不含复杂计算的符号判断任务；概念与操作分别留下表现。
3. **提供对应帮助。** 概念任务出错就补含义与条件；概念正确而符号操作出错就练对应操作；两项都正确时，再核实原题的执行与检查过程。
4. **检查独立应用。** 完成帮助后，用无提示的新函数题检查；间隔后再复查，把结果接回个人记录与下一项任务。

功能支撑：[步骤判断与诊断建议基础](../frontend/showcase/index.html#time) · 已有基础；[自适应补测与长期衔接](../frontend/showcase/index.html#longterm) · 设计方案。

### 同一道空间向量题，三名学生需要三种帮助

都答错了这道题，后续安排仍要回到各自的具体表现。

1. **甲：建系依据没有理解。** 先回到如何选择坐标系与几何条件，借助图形演示和短任务确认，再返回原题建立坐标。
2. **乙：建系和列式正确，解方程出错。** 保留已经会的部分，集中练求法向量涉及的方程与计算，再放回完整题目检查衔接。
3. **丙：会执行，却在考试中没选出方法。** 安排隐藏类别的混合题，让学生说明为何选择空间向量、条件是否适用，检验方法识别与迁移。
4. **教师：检查安排是否合适。** 分别查看三人的新题表现，决定是否继续补充；班级讲评围绕共性问题组织，个别问题进入对应任务。

功能支撑：[步骤批改与几何演示](../frontend/showcase/index.html#single) · 已有基础；[步骤补练与混合训练](../frontend/showcase/index.html#library) · 设计方案；[分组教学与后续跟进](../frontend/showcase/index.html#teacher) · 设计方案。

### 把一次作答，连成可以持续检查的教学过程

学生、教师与学校围绕同一组学习证据接续工作。

常见过程：全班做同一份作业 → 答案错误 → 看解析或等讲评 → 完成订正 → 继续下一课 → 下次考试再看是否还错。

目标过程：

1. **作答与定位。** 学生提交题目与作答，定位具体问题步骤，保留已经正确的部分和需要核实的原因。
2. **诊断与对应帮助。** 按需用短任务核实，再安排讲解、局部补练或方法识别；所有任务共同占用个人时间预算。
3. **独立验证与个人记录。** 用无提示新题和间隔复查检查变化，记录帮助条件、作答证据与下一次任务。
4. **教师组织与继续跟进。** 教师查看班级问题分布，决定个别辅导、小组补充或全班讲评，后续继续检查对应问题。
5. **学校支持与教研积累。** 学校在职责范围内观察教学调整、支持覆盖与学习变化，据此安排资源，积累经过核实的教学经验。

功能支撑：[单题共用基础](../frontend/showcase/index.html#single) · 已有基础；[长期档案与教学协同](../frontend/showcase/index.html#longterm) · 设计方案；[学校质量与教研支持](../frontend/showcase/index.html#school) · 设计方案。

数字笔迹接入后，回放可以补充最终卷面中消失的尝试：重写、自行改正和反复返回的顺序。时间线用于寻找值得核实的片段，具体原因结合推理内容、学生说明和补测表现判断。

## 社会价值怎样形成

让必要的学习帮助更普遍可得，让家庭减少对额外补课的依赖。

1. **问题在日常出现时被看见。** 作业与短诊断把具体困难接到教学，减少积累到考试之后才集中补救。
2. **帮助进入校内连续支持。** 讲解、补练与复查相互接续，教师负责关键判断与面对面支持。
3. **家庭少一些补缺式投入。** 日常学习缺口得到处理后，家庭减少为此寻找额外补课、重复购买支持的需要。
4. **必要帮助覆盖更多学生。** 经过核实的资源和经验持续复用，学校将设备、接入与教师支持共同纳入安排。

以上路径把家庭压力与日常教学支持连接起来：先让问题及时得到帮助，再观察额外补课需要、家庭投入和支持机会是否随之改变。学校的设备、网络、教师准备和完整服务成本一并进入实施安排。

## 用什么判断愿景是否实现

试点将持续观察独立新题表现、延迟保持、学生实际负担、教师净工作量、家庭投入与不同群体获得的支持，并记录设备、运行、核对、纠错和维护的完整成本。

评价同时区分原题订正与新题应用、获得提示与独立完成、即时表现与延迟保持。教师工作量记录资料组织与常规处理节省的时间，也记录审核、纠错和维护新增的时间。学校和教师的评价保留学生起点、班额、课时、资源条件与数据覆盖等背景，形成可以核对的分项依据。
