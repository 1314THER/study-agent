# 第一章：系统设计与研究亮点

让 AI 参与学习全过程，推动每一次教学。

从一道题的每一步，到一张卷的时间分配，再到一个学生的长期成长。StudyAgent 将知识、方法、过程与能力连接起来，让学生的学习、教师的教学和学校的教研相互支撑。

我们做的不是单纯减轻人类教师的负担，我们要做的是让 AI 看到人类教师无法看到的东西。

The purpose of AI is not to assist humanity, but to surpass it.

## 1. 系统性：把每个教学环节，连成同一个系统

备课、作业、刷题、考试中，不同供应商的 Agent 和人类各自运转，学生的问题却常常断在环节之间。

StudyAgent 贯穿学习、作业、训练、考试、复盘与复习，并连接教师备课、课堂教学和学校教研。各项功能共用同一套知识结构和学生档案：批改发现的问题进入训练，训练表现进入长期记录，长期记录再影响下一次出题、教学和复习安排。

每一次作答，都能成为下一次教学的起点。



## 2. 步骤与套路：让 AI 的判断，落到具体的方法与操作

现有大多数 LLM 出题和改题只是基于知识点，即使有再多训练数据，没有知识库也很难输出稳定结构化的结果。

把套路、步骤及其适用条件引入知识库，为 LLM 和教师提供共同的结构化判断依据。面对单题，可以对应学生的推导，定位错误、分步讲解并生成针对性练习；面对整卷，可以汇总知识与套路覆盖、关键步骤难度，以及学生反复出现的困难。

让 LLM 有依据地判断，让老师看得懂判断。

有了解题结构，还需要知道这些步骤是怎样发生的。

## 3. 时间维度：把失分过程，重新放回时间里

最终卷面留下了答案，却难以还原停顿、试错、回访和自我纠正。

StudyAgent 将时间贯穿三个尺度，让诊断同时看到作答内容、过程顺序和历史变化。

把错误位置、用时表现和以往能力结合起来，为知识缺口、计算熟练度与时间分配等失分原因提供更充分的判断依据。

- **一道题：**每一步何时开始、在哪里停顿、何时返回修改，帮助定位具体卡点。
- **一张卷：**每道题投入了多少时间，哪些尝试挤占了后续作答，帮助分析考试策略。
- **整个学习历程：**哪些困难长期反复，哪些进步能够保持，哪些知识需要重新复习。
看见错在哪里，也追踪问题怎样发生。

时间里积累的问题与进步，汇成一个人的能力图谱。

## 4. 能力图谱：让同一个分数背后的差异，被真正看见

同样的分数，可能对应完全不同的短板和学习路径。

为每个学生建立持续更新的能力图谱：既呈现哪个知识板块薄弱，也观察计算与执行、逻辑推理、方法迁移、数学表达与素养，以及学习和复盘习惯。作业、考试、订正和独立复测不断补充这张图谱，让学习安排随着学生的真实变化调整。

知识板块｜做题能力｜计算能力｜逻辑推理｜数学素养｜考试技巧与心态

教学面对的，是一个持续成长的人。



## 5. 数据底座：把 150 分高手的解题经验，编进系统

2×150

高考数学满分高手的解题经验

项目组成员施棋智、杨瀚淳均为高考数学满分选手。数据集由满分选手、顶级 AI 与学校数学教师共同编订：高手提炼方法与考场经验，AI 辅助拓展和校验，教师校准课堂表达与评分依据。把解题经验转成可解释、可训练、可持续更新的数据底座。

高手的方法，教师的经验，成为 AI 可以调用的知识。



## 6. 全过程参与：主动发现问题，把反馈送回教学现场

等到老师主动查询，许多反复出现的问题已经积累了很久。

系统持续观察学习过程，把值得采取行动的问题及时呈现出来：学生反复卡在同一步，提出补练建议；班级集中出现相同困难，建议调整讲评与作业；阶段性问题持续反复，为教师备课和学校教研提供反馈。教学调整之后，再通过后续作答检查是否真正改善。

发现问题，提出行动，再追踪行动的效果。



## 7. 开放与自进化：让教学能力跨越产品边界，持续生长

封闭题库中的内容和经验，难以在不同工具、不同教学环节之间流动。

面向 AI 与 Agent 时代，StudyAgent 通过开放工具接口，让解题、批改、出题和学情能力接入不同助教与教师工具。新试题、教材变化、教师纠错与后续学习结果持续进入更新流程，经过审核与评测，改进知识库、规则和模型，让一次改进服务更多教学场景。

- 在单个产品内访问内容 → 教育能力可被不同工具调用
- 人工逐条整理和维护 → AI 辅助发现、整理与校验，教师审核
- 修改停留在某道题或某项功能 → 经过验证的经验跨教学场景复用
开放连接新的工具，自进化积累新的经验。



## 收束与过渡

方法让判断有依据，时间让过程可追踪，能力图谱让教学因人而变。它们共同推动下一次练习、下一次备课和下一轮系统改进。

这套系统怎样把不同教学环节连接起来？先认识它共同使用的四个基本单位：课时、知识点、步骤与套路。
